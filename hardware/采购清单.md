## 关键接线速查

### 电机 → 驱动器

**电机相线**（粗线4根）→ 驱动器功率端口
| 线色 | 端子 |
|------|------|
| 红 | A+ |
| 蓝 | A- |
| 绿 | B+ |
| 黑 | B- |

**编码器线**（DB9散线6根）→ 驱动器编码器端口
| 线色 | 端子 |
|------|------|
| 黑 | GND |
| 红 | VCC(+5V) |
| 黄 | PA+ |
| 绿 | PA- |
| 蓝 | PB+ |
| 白 | PB- |

### 电源 → 驱动器

```
24V电源(+) → 红色线 → 3个驱动器的 VCC（并联）
24V电源(-) → 黑色线 → 3个驱动器的 GND（并联）
```

### Arduino → 驱动器（共阳极，脉冲/方向控制）

```
Arduino 5V → 所有驱动器 PLS+ 和 DIR+（红杜邦线，并联）
Arduino D2 → X轴 PLS-（蓝杜邦线）
Arduino D3 → X轴 DIR-（蓝杜邦线）
Arduino D4 → Y轴 PLS-（绿杜邦线）
Arduino D5 → Y轴 DIR-（绿杜邦线）
Arduino D6 → Z轴 PLS-（紫杜邦线）
Arduino D7 → Z轴 DIR-（紫杜邦线）
ENA+/ENA-  → 悬空不接
```

### 传感器 → Arduino（5V直连，无需转接）

```
棕色线 → Arduino 5V（9个并联）
蓝色线 → Arduino GND（9个并联）
白色线 → Arduino数字引脚（每个1根）：
  X轴：D22(负限位) D23(原点) D24(正限位)
  Y轴：D25(负限位) D26(原点) D27(正限位)
  Z轴：D28(负限位) D29(原点) D30(正限位)
```

### Z轴刹车 → DSTUR-T80 USB继电器 CH2

```
24V电源 +V    → 继电器第2路 COM
继电器第2路 NO → 电机刹车红线
电机刹车黑线   → 24V电源 -V
```

> **原理**：CH2 打开时，COM-NO 导通，24V 经过电机刹车线圈，刹车释放。
> CH2 关闭时，COM-NO 断开，刹车断电锁死（断电抱死，防Z轴下滑）。

### 夹爪 → DSTUR-T80 USB继电器 CH1

```
24V电源 +V    → 继电器第1路 COM
继电器第1路 NO → 夹爪控制器 24V控制引脚
夹爪控制器 COM- → 24V电源 -V
夹爪控制器 V+/V-（绿色端子）→ 24V电源（电机供电，常接）
```

> **原理**：CH1 打开时，24V 接通夹爪控制引脚，夹爪夹合。
> CH1 关闭时，24V 断开，夹爪松开。
> 夹爪电机供电（绿色端子 V+/V-）始终接着24V，不经过继电器。

### DSTUR-T80 USB继电器控制协议

```
端口：/dev/cu.usbmodem6670E00119391（Mac）
波特率：9600
指令格式：0xA0 [通道0x01~0x08] [0x01=ON / 0x00=OFF] [校验和]
校验和 = 通道 + 开关状态 + 0xA0（取低8位）
响应：文本，如 "CH1:ON"、"CH2:OFF"
```

> **注**：USB转RS485 适配器仍然需要，用于将来连接旋涂/移液模块，以及夹爪的 RS485 力/速度/位置调节（高级用途）。
