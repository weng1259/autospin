# GRBL `$$` 参数说明

本文记录 AutoSpinmotorSystem XYZ 导轨控制器中 GRBL `$$` 参数的含义、单位和本项目使用注意事项。

当前控制器为 `Grbl 1.2i` / grbl-Mega-5X。XYZ 使用 GRBL 的 X/Y/Z 轴，新增 Z2 在底层作为 A 轴使用。

## 当前关键结论

- `$100/$101/$102` 是 XYZ 的 steps/mm，决定“命令 1 mm 实际走多少 mm”。
- `$23` 只影响归零方向，不修正距离比例。
- `$27` 是归零触发限位后的回退距离。本项目软件软限位 `*_max_mm: -5.0` 与 `$27=5.000` 匹配。
- Python 软限位来自 `hardware/xyz_stage/constants.yaml`，不是 GRBL 的 `$130/$131/$132`。
- 当前建议值：

```text
$100=690.000
$101=690.000
$102=727.000
$23=0
$27=5.000
```

当前已实测确认的软件软限位：

```yaml
soft_limits:
  x_min_mm: -310.0
  x_max_mm: -5.0
  y_min_mm: -295.0
  y_max_mm: -5.0
  z_min_mm: -95.0
  z_max_mm: -5.0
```

## 基础与 IO 参数

| 参数 | 名称 | 单位/取值 | 含义 | 本项目备注 |
|---|---|---:|---|---|
| `$0` | Step pulse time | us | STEP 脉冲宽度。数值太小可能导致驱动器漏步。 | 当前 `10` 通常可用。 |
| `$1` | Step idle delay | ms | 运动结束后电机保持使能的时间。`255` 表示一直保持。 | 当前 `254` 接近常保持；人工模式代码可能临时改 `$1=25`。 |
| `$2` | Step pulse invert mask | bit mask | 反转各轴 STEP 脉冲电平。 | 通常不改。 |
| `$3` | Direction invert mask | bit mask | 反转各轴运动方向。 | 会影响手动运动方向，但不等同于归零方向。 |
| `$4` | Step enable invert | 0/1 | 反转步进使能信号。 | 驱动器使能异常时才改。 |
| `$5` | Limit pins invert | 0/1 | 反转限位输入电平。 | 当前 `1`，说明限位输入使用反相逻辑。 |
| `$6` | Probe pin invert | 0/1 | 反转探针输入电平。 | 本系统通常不用。 |

## 状态与单位参数

| 参数 | 名称 | 单位/取值 | 含义 | 本项目备注 |
|---|---|---:|---|---|
| `$10` | Status report mask | bit mask | 设置 `?` 状态报告内容。 | 当前 `1`，状态行会输出机器坐标。 |
| `$11` | Junction deviation | mm | 拐角速度规划容差。 | 当前 `0.020`，一般不改。 |
| `$12` | Arc tolerance | mm | 圆弧插补精度。 | XYZ 点位运动基本不受影响。 |
| `$13` | Report inches | 0/1 | 状态报告是否使用英寸。 | 必须保持 `0`，本项目全部按 mm。 |

## 限位与归零参数

| 参数 | 名称 | 单位/取值 | 含义 | 本项目备注 |
|---|---|---:|---|---|
| `$20` | Soft limits | 0/1 | GRBL 固件软限位。 | 当前 `0`。本项目主要使用 Python `constants.yaml` 软限位。 |
| `$21` | Hard limits | 0/1 | 硬限位开关报警。 | 当前 `0`。如开启，干扰会更容易触发报警。 |
| `$22` | Homing cycle | 0/1 | 是否启用 `$H` 归零。 | 当前 `1`，应保持开启。 |
| `$23` | Homing direction invert mask | bit mask | 设置归零时各轴寻找限位的方向。 | 当前 `0`。只有归零方向错时才改。 |
| `$24` | Homing locate feed | mm/min | 归零二次精找速度。 | 当前 `25.000`，低速精找。 |
| `$25` | Homing search seek | mm/min | 归零第一次寻找限位速度。 | 当前 `1500.000`。 |
| `$26` | Homing debounce | ms | 限位触发去抖时间。 | 当前 `250`。限位噪声大可适当增加。 |
| `$27` | Homing pull-off | mm | 归零触发限位后的回退距离。 | 当前 `5.000`，对应 `*_max_mm=-5.0`。 |

### `$23` bit mask 说明

`$23` 使用位掩码控制归零方向。常见 GRBL 三轴位含义如下：

| 轴 | bit | 数值 |
|---|---:|---:|
| X | bit 0 | 1 |
| Y | bit 1 | 2 |
| Z | bit 2 | 4 |

示例：

```text
$23=0  # X/Y/Z 均使用默认归零方向
$23=1  # 只反转 X 归零方向
$23=2  # 只反转 Y 归零方向
$23=3  # 同时反转 X 和 Y
$23=4  # 只反转 Z
```

grbl-Mega-5X 的 A/Z2 轴可能还有扩展 bit，具体取决于固件编译配置。不要用 `$23` 解决距离比例问题。

## 主轴/激光参数

| 参数 | 名称 | 单位/取值 | 含义 | 本项目备注 |
|---|---|---:|---|---|
| `$30` | Max spindle speed | rpm/PWM | 主轴最大转速或 PWM 上限。 | 当前 `12000`，XYZ 导轨运动基本不用。 |
| `$31` | Min spindle speed | rpm/PWM | 主轴最小转速或 PWM 下限。 | 当前 `550`，XYZ 导轨运动基本不用。 |
| `$32` | Laser mode | 0/1 | 激光模式。 | 当前 `0`，保持关闭。 |

## Steps/mm 参数

| 参数 | 轴 | 单位 | 含义 | 本项目建议 |
|---|---|---:|---|---:|
| `$100` | X | steps/mm | X 轴每毫米脉冲数。 | `690.000` |
| `$101` | Y | steps/mm | Y 轴每毫米脉冲数。 | `690.000` |
| `$102` | Z | steps/mm | Z 轴每毫米脉冲数。 | `727.000` |
| `$103` | A/Z2 | steps/mm | A 轴每毫米或每单位脉冲数；本项目作为 Z2。 | 以 Z2 实测为准。 |

### steps/mm 校准公式

如果命令移动距离和尺量实际距离不一致，使用：

```text
新 steps/mm = 当前 steps/mm * 命令移动距离 / 实际移动距离
```

本次 XYZ 校准依据：

```text
X: 400 * 100 / 58 = 689.66 -> $100=690.000
Y: 400 * 100 / 58 = 689.66 -> $101=690.000
Z: 400 * 20 / 11  = 727.27 -> $102=727.000
```

Z 轴建议后续用 50 mm 或更长距离再测一次，并按同一公式二次修正。

## 推荐写入与验证顺序

写入 steps/mm：

```text
$100=690.000
$101=690.000
$102=727.000
$$
```

确认参数保存后，归零：

```text
$H
```

低速小距离验证：

```text
G21
G91
G0 X-1 F50
G0 Y-1 F50
G0 Z-1 F50
```

确认不会复位后，再做绝对坐标测试：

```text
G21
G90
G0 X-50 F500
G0 Y-50 F500
G0 Z-20 F300
```

如果一发运动命令就重新出现 `Grbl 1.2i ['$' for help]`，说明控制板发生复位，优先检查供电、电机驱动干扰、USB 连接和是否有其他程序占用串口。
