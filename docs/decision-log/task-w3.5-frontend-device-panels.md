## 面板清单（每个 = 一个 grid 卡片：标题行 + 实时读数行 + 控件区）

统一结构：标题行 = 设备名 + 连接状态点（绿/灰/红）+ 连接/断开小按钮；读数行 = SSE 快照
实时值（等宽右对齐带单位，异常值红色）；控件区 = 紧凑网格。

1. **龙门架**：读数 X/Y/Z mm + 机器状态 + homed + 限位 Pn。控件：归零、jog 六向按钮
   （步长 select：0.5/1/5/10/50mm，进给 select）、绝对移动三输入+GO、alarm 恢复按钮
   （仅 alarm 时亮起）。
2. **加热台**：读数 PV/SV ℃。控件：SV 数字输入+设定（≤150 提示上限来源）、读 PV 按钮。
3. **旋涂**：读数 目标 RPM/运行状态/故障位。控件：RPM 输入+启动、停止（带刹车勾选，
   默认勾）、读故障按钮。加"无角度反馈"灰字说明一行。
4. **移液**：读数 位置/homed/tip 有无。控件：归零、吸/排（体积 µL 输入）、退 tip。
5. **滑台**：读数 位置 mm/homed/标志位。控件：归零、绝对移动输入+GO、**停止**（红边，
   直通不排队）。
6. **继电器 CH3-8**：六个开关行（通道号 + 用途备注可编辑存 localStorage + ON/OFF 状态）。
7. **夹爪**：读数 当前指令状态。控件：夹紧/张开两按钮。

交互规则：
- 写操作统一走 `api()`：请求发出→该面板控件禁用并显示 operation id→SSE 快照
  `last_operation` 完成→解禁；**急停与滑台停止永不禁用**。
- 409 响应：状态栏显示"被 <设备·动作> 占用（已运行 Xs）"，不弹 alert。
- 所有错误显示 `human_message` + `suggested_action_zh`（结构化 JSON 已带）。
- 数值输入用 `<input type="number">` 带 min/max/step，超界浏览器层先拦一道。
