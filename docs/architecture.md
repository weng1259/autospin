# 智能旋涂仪 — 系统架构

## 当前架构（调试阶段）

```
电脑 (Mac)
  │
  ├── USB串口① (115200 baud) → Arduino Mega 2560
  │                               ├── GPIO D2-D7 脉冲/方向 → 驱动器 × 3 → 步进电机 × 3（闭环）
  │                               ├── GPIO D22-D30 数字输入 ← 光电传感器 × 9（已接通，已测试）
  │                               └── GPIO D31-D33 数字输入 ← 驱动器 ALM 报警 × 3（待接线）
  │
  ├── USB串口② (9600 baud) → DSTUR-T80 USB继电器（8路，光耦隔离）
  │                             ├── CH1 → 夹爪24V控制（通电=夹合，断电=松开）
  │                             ├── CH2 → Z轴刹车24V（通电=释放刹车）
  │                             └── CH3~CH8 → 备用
  │
  └── USB转RS485 → RS485 总线（待接入）
                     ├── 旋涂模块
                     └── 移液模块

电源：24V 15A 开关电源 → 驱动器 × 3 + 继电器负载（刹车、夹爪）
Arduino：USB 供电
DSTUR-T80：USB 供电（5~32V），继电器触点接24V电源控制外部设备
```

### 设计决策：RS485 不经过 Arduino

RS485 设备（旋涂模块、移液模块）直接由上位机控制，不经过 Arduino，原因：

1. **职责分离**：Arduino 专注实时脉冲生成，上位机处理 RS485 命令/响应协议
2. **互不干扰**：电机脉冲生成不会被 RS485 通信打断
3. **调试方便**：两条总线可以独立测试
4. **上位机更适合**：Python pymodbus/minimalmodbus 库成熟，处理 Modbus 协议更方便
5. **Arduino 固件保持简单**：不需要加 RS485 代码

### 设计决策：USB继电器控制夹爪和刹车

夹爪和Z轴刹车都是简单的"通电/断电"控制，使用 DSTUR-T80 USB继电器模块而非 Arduino GPIO，原因：

1. **电气隔离**：继电器模块光耦隔离，24V负载不会影响Arduino
2. **即插即用**：USB串口控制，不需要额外接线到Arduino
3. **扩展性好**：8路继电器，夹爪和刹车只用2路，剩余6路留给将来扩展
4. **协议简单**：9600波特率，3字节指令（0xA0 + 通道 + 开关 + 校验和），响应为文本（如"CH1:ON"）
5. **Arduino 引脚不够用**：Arduino 已经被电机脉冲和传感器占满

## 目标架构

```
用户设备（Mac/手机）
  │
  │ WiFi
  ↓
树莓派（上位机）
  ├── REST API / WebSocket
  ├── 实验流程编排（Python）
  │
  ├── USB串口① → Arduino Mega 2560（下位机）
  │                 ├── 脉冲/方向 → XYZ 电机（定位）
  │                 └── 读传感器 → 限位/原点（安全保护）
  │
  ├── USB串口② → DSTUR-T80 USB继电器
  │                 ├── CH1 → 夹爪（24V通断控制）
  │                 ├── CH2 → Z轴刹车（24V通断控制）
  │                 └── CH3~CH8 → 备用（旋涂阀门等）
  │
  └── USB转RS485 → RS485 总线
                     ├── 旋涂模块（旋涂控制）
                     ├── 移液模块（移液控制）
                     └── 夹爪力/速度/位置调节（可选，高级用途）
```

### 电机 → 驱动器

```
红 → A+    蓝 → A-    绿 → B+    黑 → B-
```

### 驱动器拨码开关

```
SW1=OFF  SW2=OFF  SW3=OFF  SW4=OFF  SW5=OFF  SW6=ON  SW7=OFF  SW8=OFF（闭环，DB9编码器已连接）
细分 = 51200 脉冲/转（HTD3M 25齿 × 3mm = 75mm/转 → 682.67 步/mm，详见 docs/hardware-specs.md）
```
