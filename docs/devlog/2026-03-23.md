## 遇到的问题

- 传感器逻辑反了：DS-ES61 是 NPN 亮通型，槽内无遮挡时 NPN 导通拉 LOW，有遮挡时变 HIGH
- 初始代码用 `LOW == 触发`，导致一上来就显示全部触发

## 解决方案

- 将固件中判断逻辑改为 `HIGH == 触发`（`digitalRead() == HIGH ? '1' : '0'`）
