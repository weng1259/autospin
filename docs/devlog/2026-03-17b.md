# 开发日志 — 2026-03-17（Z轴卡顿排查）

FENG

## 今日工作

- 首次通电测试，X/Y轴运动正常
- 发现 Z 轴运动时有明显卡顿和"咚咚"异响
- 排查并定位问题根因：Z轴刹车未释放

## 遇到的问题

- Z轴移动时有节律性卡顿和撞击声，X/Y轴完全正常

## 解决方案

- **根因**：Z轴电机 `57J1880EC-1000-LS-SCG` 带断电抱死型刹车（LS=刹车），不通24V时刹车锁死，电机在跟锁死的刹车硬拧
- **临时方案**：将Z轴电机的2根刹车线（红+黑细线）直接接24V电源 +V/-V，手动释放刹车。接上后应听到"咔"声
- **正式方案**：等继电器到货后按教程接线，通过驱动器 BRAKE 信号自动控制
- **注意**：临时方案下断电后Z轴会因重力下滑，仅限测试使用
