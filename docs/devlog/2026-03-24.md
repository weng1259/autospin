## 步距实测

产品画册确认传动方式：**HTD3M 同步带 × 25 齿** → 每转行程 = 3mm × 25 = **75mm/转**

拨码 SW3-SW6 标称 3200 细分，但闭环模式下实测：

| 脉冲数 | 观察结果 |
|-------|---------|
| 200 | 约 3/4 圈 |
| 300 | 差一点到一圈 |
| 350 | 刚过一圈 |
| 400 | 多了约 1/4 圈 |

→ 实测 **~320 脉冲/转**（闭环下有效细分 = 标称 ÷ 10）

```
320 脉冲/转 ÷ 75mm/转 ≈ 4.27 步/mm
最小步距 ≈ 0.234mm
```

之前文档中所有步距值（80、640、1280、42.67 步/mm）均错误，待调参确定最终细分后统一更新。

### 细分调整验证

将 SW5 从 ON 改为 OFF → SW3=OFF SW4=OFF SW5=OFF SW6=ON（标称 51200 细分）

实测：5000 脉冲 ≈ 1 圈 → 闭环实测 **~5120 脉冲/转**，确认"÷10"规律成立。

**最终采用参数**：
```
拨码：SW3=OFF SW4=OFF SW5=OFF SW6=ON（51200）
闭环实测：~5120 脉冲/转 ← ⚠️ 此实测值可能有误，见下方注释
传动：HTD3M × 25齿 = 75mm/转
steps/mm = 5120 ÷ 75 ≈ 68.3 ← ⚠️ 已修正为 51200 ÷ 75 = 682.67
最小步距 ≈ 0.015mm
```

> **2026-03-25 修正**：上述"闭环实测 ~5120 脉冲/转"存疑。按驱动器手册 p15 细分表，
> SW3-6=OFF/OFF/OFF/ON 对应 51200 脉冲/转，不存在"÷10"规律。
> 正确计算：51200 ÷ 75 = **682.67 步/mm**。详见 `docs/hardware-specs.md`。
> **2026-03-26 已实测确认**：MOVE 6827 步 ≈ 10mm，682.67 步/mm 正确。

## Phase 2a 固件重构

文件：`firmware/motor_control/motor_control.ino`

- 将旧两字符测试协议替换为新行文本协议（命令以 `\n` 结尾）
- 新增状态机骨架：`IDLE` / `MOVING` / `ERROR` / `ESTOP`
