## 遇到的问题

1. Arduino 只有2个5V引脚，但需给3个驱动器共6个端子（PLS+/DIR+）供5V
2. 3根杜邦线无法同时插进 Arduino 同一5V引脚
3. 信号线误接模拟引脚（A2/A3），应接数字引脚 D2-D7
4. 不熟悉 Arduino Mega 引脚排布（D22-D53大排 vs D0-D13小排）
5. 上传固件时串口被Web Serial API后台占用，关闭网页仍无法释放，需重启电脑
6. X轴和Z轴方向与网页控制面板中的预期方向相反

## 解决方案

1. 驱动器端子之间用短线跳接，串联传递5V，每个Arduino引脚只插1根线
2. 同上，跳接方案解决
3. D2-D7 位于 USB 口旁的小排针（DIGITAL），非大排针区域
4. 根据实物照片标注引脚位置
5. **关键经验**：上传固件前必须先关闭网页控制面板，否则需重启电脑恢复串口
6. 在固件中对调 X/Z 轴的 HIGH/LOW 方向逻辑
