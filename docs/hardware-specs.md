## 二、驱动器（2HSS57-C）

> 📗 驱动器手册

### 2.1 技术指标（📗 p9）

| 参数 | 值 |
|------|-----|
| 输入电压 | 24~60VDC（典型 36V，实际使用 24V） |
| 连续电流 | 4.5A 20kHz PWM |
| **最大脉冲频率** | **200kHz** |
| 保护 | 过流 8A±10%、过压 70VDC、位置超差可调 |

### 2.2 脉冲时序要求（📗 p13）

| 参数 | 最小值 | 固件实际值 |
|------|--------|-----------|
| 脉冲宽度（t3/t4） | **≥ 2.5μs** | 当前最小 25μs（SPEED 9） |
| DIR 建立时间（t2） | **≥ 6μs** | 10μs |
| ENA 建立时间（t1） | ≥ 5μs | — |

### 2.3 拨码开关设置（📗 p14-16）

当前三台驱动器相同设置：

| 开关 | 状态 | 功能 |
|------|------|------|
| SW1 | OFF | 单脉冲模式（脉冲+方向） |
| SW2 | OFF | 默认方向（CCW） |
| SW3 | OFF | 细分设置 ↓ |
| SW4 | OFF | 细分设置 ↓ |
| SW5 | OFF | 细分设置 ↓ |
| SW6 | ON | → 组合 = **51200 细分/转** |
| SW7 | OFF | 指令平滑关闭 |
| SW8 | **OFF** | **闭环模式**（需 DB9 编码器） |

### 2.5 关键内部参数（📗 p19-20）

| 参数 | 名称 | 默认值 | 说明 |
|------|------|--------|------|
| P15 | 编码器线数选择 | 0 | 0=1000线, 1=2500线 |
| P16 | 位置超差阈值 | 400（×10=4000 counts） | 超过此值触发报警5 |
| P19 | 指令平滑 | 2 | |
| P20 | 自定义细分 | 8（×50=400） | SW3-6全ON时生效 |
| P22 | 脉冲滤波 | 3 | |

### 2.6 接线方式（📗 p10 + p18）

- 控制信号：**共阳极**接法（Arduino 5V → PLS+/DIR+，GPIO → PLS-/DIR-）
- 编码器：1000 线，四倍频计数 → 4000 counts/转（📗 p18）
- 刹车输出：集电极开路，需外接 24V + 继电器（📗 p6）
- ENA+/ENA-：当前悬空未接

## 三、计算参数

### 3.1 步距计算

```
每转脉冲数 = 51200（DIP 开关设定）
每转行程 = 75mm（同步带 25齿 × 3mm 齿距）
步距 = 51200 ÷ 75 = 682.67 步/mm
```

> ~~旧值"68.3步/mm"和"80步/mm"均不正确，来自早期"闭环÷10"的错误假设。~~
> **2026-03-26 已实测确认**：MOVE 6827 步 ≈ 10mm，682.67 步/mm 正确。

## 四、各轴物理特征

> 🔧 以下参数从实机测试获得，手册/画册中无法直接查到

| 参数 | X 轴 | Y 轴 | Z 轴 |
|------|------|------|------|
| 固件 invertDir | **true** | false | **false** |
| 归零方向 | 负方向（左） | 负方向（前） | **正方向（上）** |
| homeDirectionPositive | false | false | **true** |
| 原点传感器位置 | 左端 | 前端 | **顶部** |
| 引脚 PLS/DIR | D2/D3 | D4/D5 | D6/D7 |
| 传感器引脚 | D22/D23/D24 | D25/D26/D27 | D28/D29/D30 |
| 有刹车 | 否 | 否 | **是（DSTUR-T80 CH2）** |

### Z 轴刹车操作

```
运动前：发继电器命令 CH2 ON → 等 0.5s → 再发运动命令
运动后：收到运动完成 → 发继电器命令 CH2 OFF
注意：刹车未释放时发脉冲 → 闭环驱动器位置偏差报警（红灯闪5次）
```
