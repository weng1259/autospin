## 一、认识你的零件

打开包裹后，你会看到很多零件。别慌，我们先一个一个认识它们。

### 1.1 同步带模组（共4根，是最大的零件）

**长什么样**：一根长条形的银色铝型材，上面有一个可以滑动的方块（叫"滑块"），里面藏着一根橡胶/塑料的带子（同步带）。

你有4根，长度不同：
- **最长的1根**（梁长596mm，约60厘米）→ 这是 **X轴**，横向的横梁
- **中等长度2根**（梁长422mm，约42厘米）→ 这是 **Y轴**，底部的两根平行轨道
- **最短的1根**（梁长222mm，约22厘米）→ 这是 **Z轴**，上下移动的那根

**怎么区分**：拿尺子量一下长度就能分清。如果没有尺子，把4根并排放一起，一眼就能看出长短。

**模组上的关键部位**：
- **滑块**：模组上那个能前后滑动的方块，后面我们要在上面装连接板
- **两端的端盖**：模组两头各有一个盖子。其中一端（或两端）会露出一截金属轴（圆柱形的棒子），这个轴用来连接电机或连接杆
- **铝型材槽**：模组侧面有T型的凹槽，后面要在里面装光电开关

### 1.2 电机（共3个）

**长什么样**：方方的黑色/银色金属块，正面中心伸出一根圆柱形的轴（直径约8mm），背面拖着一束彩色电线。大约一个拳头大小。

你有3个电机：
- **2个普通电机**：背面出来的线比较少（通常4根信号线 + 编码器线）
- **1个带刹车的电机**：比普通电机稍微长一点/重一点，背面会**多出2根线**（刹车线）。这个电机是给Z轴用的（防止断电后Z轴掉下来）

**怎么区分**：带刹车的那个电机通常比另外两个多出一对线（可能是红色和黑色），或者商家会贴标签标注。如果分不清，先把3个电机放在一起比较，找出那个"不一样"的。

### 1.3 驱动器（共3个）

**长什么样**：一个扁平的长方形金属盒子，一面有很多接线端子（一排小方孔，用来插电线），另一面可能有散热片。大约手掌大小。

**作用**：驱动器是电机的"大脑"，接收控制信号后让电机转动。每个电机配一个驱动器。

**现在先不用管它**，组装机械结构时用不到，等接线阶段再用。

### 1.4 电机笼（共3个）

**长什么样**：一个金属框架/支架，中间有一个圆孔（刚好能放进电机），四周有螺丝孔。像一个"U形"或"口形"的小架子。

**作用**：把电机固定在模组端头上。电机先装进电机笼，电机笼再装到模组上。

### 1.5 联轴器（共5个，两种规格）

**长什么样**：一个小圆柱形的金属件，两头各有一个孔（用来插轴），侧面有小螺丝（叫"紧定螺钉"，用内六角扳手拧）。大约大拇指大小。

你有两种：
- **12×8 联轴器**（3个）：一头孔径12mm，一头孔径8mm。用来连接电机轴（8mm）和模组轴（12mm）
- **12×12 联轴器**（2个）：两头孔径都是12mm。用来连接Y轴的连接杆

**怎么区分**：看联轴器两头的孔大小。如果两头一样大，就是12×12的；如果一头大一头小，就是12×8的。也可以试着把电机轴插进去——能插进去的那头就是8mm的孔。

### 1.6 连接杆（1根）

**长什么样**：一根光滑的金属圆棒，直径约12mm（约一根筷子粗），长度约409mm（约40厘米）。

**作用**：把左右两根Y轴模组连接起来，让它们同步运动。当一个电机转动时，通过这根杆子，两根Y轴会一起动。

### 1.7 L型板（2块）

**长什么样**：一块L形（直角弯折）的金属板，上面有若干螺丝孔。像一个书立的形状。

**作用**：安装在Y轴滑块上，用来支撑和连接X轴横梁。左右各一块。

### 1.8 T型板（1块）

**长什么样**：一块T形或方形的金属板，上面有螺丝孔。

**作用**：安装在X轴滑块上，用来挂Z轴模组。

### 1.9 地脚/固定座（4个）

**长什么样**：小的金属块或角码，带螺丝孔，有的底部有橡胶垫。

**作用**：把Y轴模组固定在桌面或底板上。每根Y轴模组两端各一个，共4个。

### 1.10 光电开关+座（9套）

**长什么样**：
- **光电开关**：一个小的黑色塑料件，U形缺口（像一个小叉子），带一根细电线（通常3根线：棕/蓝/黑 或 红/黑/白）
- **开关座**：一个小金属片或塑料座，用来把光电开关固定到模组铝型材上

**作用**：检测滑块的位置。当滑块上的感应片经过光电开关的U形缺口时，开关会发出信号。每个轴需要3个（一个确定原点位置，两个防止滑块跑过头）。

### 1.11 感应片（3个）

**长什么样**：很小的金属薄片，像一个小旗子，带螺丝孔。

**作用**：装在滑块上，经过光电开关时触发信号。每个轴的滑块上装一个。

### 1.12 螺丝配件包

商家通常会配一包螺丝。打开后你会看到各种大小的螺丝、螺母、垫片。**先不要拆散**，等到每一步需要的时候再找对应的螺丝。

## 二、准备工具

### 必须要有的工具

1. **内六角扳手套装**
   - 长什么样：L形的六角形细棒，一套通常有很多根不同大小的
   - 你需要的尺寸：**3mm、4mm、5mm**（这三把最常用）
   - 哪里买：五金店、淘宝搜"内六角扳手套装"，几块钱一套
   - **如果商家在螺丝包里配了扳手就不用另外买**

2. **十字螺丝刀**（中号）
   - 用来拧一些十字头的螺丝

3. **尺子或卷尺**
   - 用来量模组长度、确认间距

### 建议有的工具

4. **万用表**（后续接线必须用，组装阶段可以先不用）
5. **记号笔/胶带**：给零件做标记

## 三、组装前的准备工作

### 步骤 3.1：找一个干净宽敞的桌面

- 桌面至少需要 **80cm × 60cm** 的空间
- 把桌面清理干净，铺一块布或者纸板（防止划伤零件和桌面）

### 步骤 3.2：清点零件

把所有零件从包装里取出来，按照上面"认识你的零件"部分，逐一清点：

清点检查表（打勾确认）：

- [ ] 同步带模组 长的（~60cm）× 1根 → 贴标签写 **"X轴"**
- [ ] 同步带模组 中等（~42cm）× 2根 → 贴标签写 **"Y轴左"** 和 **"Y轴右"**
- [ ] 同步带模组 短的（~22cm）× 1根 → 贴标签写 **"Z轴"**
- [ ] 电机（普通）× 2个
- [ ] 电机（带刹车，线更多/更重）× 1个 → 贴标签写 **"Z轴电机"**
- [ ] 驱动器 × 3个（先放一边）
- [ ] 电机笼 × 3个
- [ ] 联轴器 12×8（一大一小孔）× 3个
- [ ] 联轴器 12×12（两头一样大）× 2个
- [ ] 连接杆（光滑圆棒，~40cm）× 1根
- [ ] L型板 × 2块
- [ ] T型板 × 1块
- [ ] 地脚/固定座 × 4个
- [ ] 光电开关 × 9个
- [ ] 开关座 × 9个
- [ ] 感应片 × 3个
- [ ] 螺丝配件包 × 1包

> **如果缺少任何零件，先联系商家补发，不要强行组装。**

### 步骤 3.3：给模组贴标签

这一步很重要！用胶带+记号笔给4根模组分别标注名字，避免后面搞混：
- 最长的 → **X轴**
- 中等的两根 → **Y轴左** 和 **Y轴右**（先随便定，后面可以换）
- 最短的 → **Z轴**

### 步骤 3.4：了解模组的方向

拿起任意一根模组，观察两个端头：

- **一端**会露出一截圆柱形的金属轴 → 这是**出轴端**（用来连接电机或连接杆的）
- **另一端**可能没有轴露出来，或者也有轴（双出轴）

**重要**：Y轴的两根模组（422mm），它们应该都是**双出轴**的（两端都有轴），因为一端要接电机，另一端要接连接杆来同步两根Y轴。

X轴的模组（596mm）备注写了"出轴D"，Z轴（222mm）备注写了"出轴C"，具体出轴方式以实物为准。

## 四、第一阶段：固定Y轴模组（底座）

> Y轴是整个龙门架的底座，所有东西都建立在它上面，所以必须装好、装正。

### 步骤 4.1：确定Y轴摆放方向

1. 拿出标记为 **"Y轴左"** 和 **"Y轴右"** 的两根模组（422mm的）
2. 把它们平行地放在桌面上
3. **滑块朝上**（滑块是模组上那个能前后滑的方块，它的平面应该朝上，后面要在上面装东西）
4. 两根模组的出轴端朝向**同一个方向**（比如都朝向你的左手边）

### 步骤 4.2：确定两根Y轴之间的间距

两根Y轴之间的距离不是随便放的，需要匹配X轴横梁的安装位置：

1. 拿出 **X轴模组**（596mm，最长的那根）和 **2块L型板**
2. 不用装螺丝，只是先**比划**一下：
   - 把L型板放在Y轴滑块上
   - 把X轴模组横着搭在两块L型板上
   - 调整两根Y轴的间距，让X轴模组能刚好通过L型板架在两根Y轴的滑块上
3. 量一下此时两根Y轴模组中心之间的距离，**用记号笔在桌面上做标记**
4. 把X轴和L型板先拿开

### 步骤 4.3：安装地脚

1. 拿出 **4个地脚/固定座**
2. 在每根Y轴模组的**两端底部**各装一个地脚
3. 找到地脚上的螺丝孔和模组底部的螺丝孔
4. 用合适的螺丝（从螺丝包里找，试一下哪个能拧进去）把地脚固定到模组上
5. 用 **内六角扳手**（通常是4mm或5mm）拧紧

### 步骤 4.4：把Y轴固定到桌面

1. 按照步骤4.2量好的间距，把两根装好地脚的Y轴模组平行放好
2. 用螺丝通过地脚底部的孔固定到桌面（如果桌面不能打孔，可以先用夹子固定，后面再想办法）
3. **检查要点**：
   - 两根Y轴是否**平行**？（量两端的间距，应该一样）
   - 两根Y轴是否**等高**？（两根模组的上表面应该在同一水平面）
   - 滑块是否都**朝上**？
   - 出轴端是否朝**同一方向**？

> **这一步非常重要**，如果两根Y轴不平行或不等高，后面整个龙门架都会歪。花点时间仔细调整。

### 步骤 4.5：自检

- 用手推动两个Y轴滑块，它们应该各自能自由滑动，没有卡顿
- 如果某个滑块推起来很紧或有异响，检查模组有没有装歪或被挤压

## 五、第二阶段：安装Y轴连接杆（同步两根Y轴）

> 这根连接杆的作用是让左右两根Y轴"绑定"在一起，动一根另一根也跟着动。

### 步骤 5.1：找到Y轴模组上要接连接杆的轴

1. 观察两根Y轴模组，在**非电机安装端**（你选定的那一端），应该各有一截圆柱形的轴从端盖里伸出来
2. 这两截轴的直径是 **12mm**

> 如果两端都有轴露出来，那电机端和连接杆端都可以，你先选一端作为连接杆端，另一端后面装电机。

### 步骤 5.2：安装联轴器到连接杆

1. 拿出 **连接杆**（φ12×409mm的圆棒）和 **2个12×12联轴器**（两头孔一样大的那种）
2. 把一个联轴器套到连接杆的一头
   - 联轴器的孔应该刚好能套进12mm的连接杆
   - 先不要拧紧侧面的螺丝
3. 把另一个联轴器套到连接杆的另一头

### 步骤 5.3：连接到Y轴模组

1. 把连接杆的一端（带着联轴器）对准 **Y轴左** 模组的出轴，把联轴器套上去
   - 联轴器里面现在穿着两根轴：连接杆和模组的轴
2. 把连接杆的另一端对准 **Y轴右** 模组的出轴，同样套上去
3. 现在连接杆横跨在两根Y轴模组之间

### 步骤 5.4：对齐并拧紧

1. 确保连接杆两端插入联轴器的**深度一致**
2. 用 **内六角扳手**（通常3mm）拧紧每个联轴器侧面的**紧定螺钉**（一般每个联轴器有2-4颗小螺丝）
3. 两头都要拧紧

### 步骤 5.5：验证同步效果

1. 用手轻轻推 **Y轴左** 的滑块
2. 观察 **Y轴右** 的滑块是否**同步移动**
3. 再推Y轴右的滑块，看左边是否也跟着动
4. 两个滑块应该始终保持在同一位置（前后位置一致）

> **如果不同步**：检查联轴器是否拧紧，连接杆是否松动。

## 六、第三阶段：安装Y轴电机

> 只需要1个电机驱动Y轴（连接杆会把动力传给另一根）。

### 步骤 6.1：找到电机安装端

- 在两根Y轴模组中，选择其中一根（比如Y轴左）
- 找到它**没有接连接杆的那一端**（另一个出轴端）
- 这就是装电机的位置

### 步骤 6.2：安装电机笼到模组

1. 拿出一个 **电机笼**
2. 电机笼上有螺丝孔，模组端头上也有对应的螺丝孔
3. 把电机笼对准模组的端头，用螺丝固定上去
4. 用内六角扳手拧紧（通常4mm或5mm）

### 步骤 6.3：安装联轴器

1. 拿出一个 **12×8 联轴器**（一头大一头小的）
2. 找到模组出轴端伸出来的那截轴（12mm粗的）
3. 把联轴器的 **大孔端（12mm）** 套到模组的轴上
4. 先用内六角扳手**轻轻拧紧**大孔端的紧定螺钉（先固定住，后面可能要微调）

### 步骤 6.4：安装电机

1. 拿出一个**普通电机**（不是带刹车的那个！）
2. 电机正面中心有一根轴（8mm粗）
3. 把电机的轴插入联轴器的**小孔端（8mm）**
4. 把电机放进电机笼里，对准螺丝孔
5. 用螺丝把电机固定在电机笼上
6. 拧紧联轴器小孔端的紧定螺钉

### 步骤 6.5：验证

1. **轻轻**用手转动电机背面的轴（或者推滑块）
2. 两个Y轴滑块应该一起移动
3. 运动应该平滑，没有卡顿

> 电机的电线先束扎好，放在一边，后面接线阶段再处理。

---

## 七、第四阶段：安装X轴横梁

> X轴是架在两根Y轴上的横梁，左右两端通过L型板连接到Y轴滑块上。

### 步骤 7.1：安装L型板到Y轴滑块

1. 拿出 **2块L型板**
2. 先把两个Y轴的滑块推到**模组中间位置**（给自己留出操作空间）
3. 把一块L型板放在 **Y轴左** 的滑块上
4. 观察L型板的形状——它是L形的，一个面是**水平的**（贴在滑块上），另一个面是**竖直的**（朝上伸出来，用来连接X轴）
5. 找到滑块上的螺丝孔和L型板上的对应螺丝孔
6. 用螺丝固定，先**不要完全拧死**（后面可能要微调位置）
7. 同样的方法，在 **Y轴右** 的滑块上装另一块L型板

### 步骤 7.2：安装X轴模组到L型板

1. 拿出标记为 **"X轴"** 的模组（596mm，最长的那根）
2. 把X轴模组**横着**放，滑块朝前（面向你）
3. X轴模组的两端要分别与左右两块L型板的竖直面对齐
4. 用螺丝把X轴模组两端固定到L型板上

### 步骤 7.3：调整和拧紧

1. 检查X轴是否与Y轴**垂直**（从上往下看应该形成一个"十"字或"H"形）
2. 用手推动Y轴（前后推），X轴横梁应该整体平稳地前后移动
3. 用手推动X轴滑块（左右推），它应该能在横梁上左右平滑移动
4. 确认一切正常后，**把所有螺丝拧紧**

### 步骤 7.4：自检

从上往下看，你现在应该看到一个 **"H"形** 的结构：
```
   Y轴左          Y轴右
    |                |
    |                |
    |===== X轴 =====|     ← X轴横梁架在两根Y轴上
    |                |
    |                |
```

- Y轴滑块前后推：X轴整体前后移动 ✓
- X轴滑块左右推：滑块在X轴横梁上左右移动 ✓
- 没有卡顿和异响 ✓

## 八、第五阶段：安装X轴电机

> 和Y轴电机一样的步骤，只是装到X轴模组上。

### 步骤 8.1：确定X轴电机安装端

- 观察X轴模组的两个端头，选择有出轴的那端（如果两端都有，选哪端都行）

### 步骤 8.2：安装电机笼

1. 拿出第二个 **电机笼**
2. 用螺丝把电机笼固定到X轴模组的电机安装端

### 步骤 8.3：安装联轴器和电机

1. 拿出第二个 **12×8 联轴器**
2. 大孔端（12mm）套到X轴模组的出轴上，轻轻拧紧
3. 拿出第二个**普通电机**（还是不要用带刹车的那个！）
4. 电机轴插入联轴器小孔端（8mm）
5. 电机装入电机笼，拧螺丝固定
6. 拧紧联轴器的紧定螺钉

### 步骤 8.4：验证

- 推X轴滑块，它应该能在横梁上左右平滑移动

## 九、第六阶段：安装Z轴模组

> Z轴是垂直的，通过T型板挂在X轴滑块上，用来实现上下运动。

### 步骤 9.1：安装T型板到X轴滑块

1. 把X轴的滑块推到**中间位置**
2. 拿出 **T型板**
3. 把T型板用螺丝固定到X轴滑块上
4. T型板应该有一个面朝前（竖直方向），用来连接Z轴模组

### 步骤 9.2：安装Z轴模组

1. 拿出标记为 **"Z轴"** 的模组（222mm，最短的那根）
2. Z轴模组需要**竖直安装**（上下方向）
3. 把Z轴模组用螺丝固定到T型板的竖直面上
4. **滑块应该能上下滑动**

### 步骤 9.3：确认方向

- Z轴的电机安装端应该在**上方**
- Z轴的滑块就是将来安装旋涂头的地方

### 步骤 9.4：自检

用手轻轻上下推Z轴滑块：
- 能平滑上下移动 ✓
- 松手后滑块可能会因为重力**自然下滑**，这是正常的（后面电机的刹车会解决这个问题）

## 十、第七阶段：安装Z轴电机（带刹车）

> **重要**：Z轴必须用那个带刹车的电机！因为Z轴是垂直的，断电后刹车能防止滑块掉下来。

### 步骤 10.1：安装电机笼

1. 拿出最后一个 **电机笼**
2. 固定到Z轴模组的**上端**

### 步骤 10.2：安装联轴器和电机

1. 拿出最后一个 **12×8 联轴器**
2. 大孔端套到Z轴模组上端的出轴上
3. 拿出那个**带刹车的电机**（之前标记为"Z轴电机"的那个）
4. 电机轴插入联轴器小孔端
5. 电机装入电机笼，拧螺丝固定
6. 拧紧联轴器

### 步骤 10.3：注意电机的线

带刹车的电机会有**更多的线**：
- 电机驱动线（连到驱动器）
- 编码器线（连到驱动器）
- **刹车线**（通常多出来的2根线，后面需要接到24V电源/继电器）

现在先把所有线整理好，用扎带或胶带绑好，避免缠绕。

## 十一、第八阶段：安装光电传感器

> 传感器型号：大深(DASS) DS-ES61 槽型光电传感器
> 作用：让控制系统知道滑块在哪个位置，防止滑块跑出范围撞坏机器。

### 步骤 11.0：先认识你的传感器零件

你手上应该有这些东西：

**光电传感器 × 9个**

长什么样：黑色塑料件，一端有一个 **U形缺口**（像一个小叉子），另一端拖着一根约2米长的黑色电线，线的末端有3根彩色细线（棕色、蓝色、白色）。

```
  传感器长这样（从侧面看）：

  ┌──┐  ┌──┐
  │  │  │  │   ← U形缺口（感应片从这里穿过）
  │  └──┘  │
  │        │
  └────────┘
      │
      │  ← 电线（2米长，末端有棕/蓝/白3根线）
```

**感应片 × 3个**（银色金属片）

长什么样：一片银色的薄金属片，顶部有一个**弯折的小舌头**（约90°弯起来的），底部有一个**长条形的孔**。比大拇指稍大一点。

```
  感应片长这样：

      ┌─┐ ← 弯折的小舌头（这部分穿过传感器U形缺口，挡住光线）
      │ │
  ┌───┘ └───┐
  │         │
  │  ┌───┐  │
  │  │   │  │ ← 长条孔（螺丝从这里穿过固定到滑块上，长条形方便微调位置）
  │  └───┘  │
  └─────────┘
```

**传感器安装座 × 9个**（黑色小金属片）

长什么样：一块黑色的小金属片，上面有**2个小孔**（固定传感器用）和**1个大孔**（固定到铝型材T型槽用）。大约2cm×1.5cm大小。

```
  安装座长这样：

  ○───────○  ← 两个小孔（用小螺丝把传感器固定在这上面）
  │       │
  │   ●   │  ← 一个大孔（螺丝穿过这里，拧进T型槽里的T型螺母）
  │       │
  ○───────○
```

---

### 步骤 11.1：理解为什么要装9个传感器

每个轴需要 **3个传感器**，各有不同作用：

```
  以Y轴为例（从上面看模组）：

  ← 滑块移动方向 →

  [负限位]      [原点]                        [正限位]
     ↓            ↓                              ↓
     U            U                              U      ← 3个传感器
  ===●============●==============================●=== 模组
     ↑            ↑                              ↑
  滑块跑到这里    滑块的"零位"                 滑块跑到这里
  就必须停下来    每次开机回到这个位置         也必须停下来
  （防撞左边）                                （防撞右边）
```

- **负限位传感器**：装在行程最左端（或最前端），滑块到这里就停，防止撞机
- **原点传感器**：装在靠近负限位的位置，开机时滑块会自动找到这里作为"零点"
- **正限位传感器**：装在行程最右端（或最后端），滑块到这里就停，防止撞机

3个轴 × 3个传感器 = **9个传感器**
每个轴的滑块上装 **1个感应片** = **3个感应片**

---

### 步骤 11.2：安装感应片到滑块

**每个轴的滑块上装1个感应片**，滑块移动时感应片跟着走，经过传感器U形缺口时触发信号。

操作步骤（以Y轴为例）：

1. 观察Y轴的滑块**侧面**，找到有螺丝孔的位置（通常是M3或M4的螺纹孔）
2. 拿一个银色感应片，**弯折的小舌头朝上**（远离模组方向）
3. 把感应片的**长条孔**对准滑块侧面的螺丝孔
4. 用螺丝穿过长条孔，拧进滑块的螺纹孔里
5. **先不要拧死**，长条孔可以上下微调位置

```
  安装后的样子（模组截面看）：

       滑块
  ┌──────────┐
  │          │  ┌─┐ ← 感应片弯折的小舌头（朝外伸出来）
  │          ├──┘ │
  │          │螺丝→●  ← 螺丝穿过长条孔固定到滑块上
  │          ├────┘
  └──────────┘
  ══════════════════ 模组铝型材

  小舌头就是要穿进传感器U形缺口的部分
```

6. 检查：弯折的小舌头伸出来的方向要和铝型材T型槽在同一侧（因为传感器装在T型槽上，小舌头要能够到传感器的U形缺口）
7. 用手推滑块来回移动，感应片不应该碰到铝型材
8. X轴和Z轴的滑块同样操作，各装1个感应片

---

### 步骤 11.3：安装传感器座到铝型材T型槽

传感器座要安装到模组铝型材**侧面的T型槽**里。

**什么是T型槽**：铝型材的四个侧面各有一条长长的凹槽，截面像字母T：

```
  铝型材侧面的T型槽截面：

  ──────────────
  │            │ ← 铝型材外壁
  │  ┌────┐   │
  ├──┘    └──┤ ← 窄口（约8mm宽）
  │          │
  │  宽槽    │ ← 里面比口子宽
  │          │
  ──────────────
```

安装方法：

1. 找到感应片伸出来的那一面对应的铝型材T型槽（感应片舌头朝哪边，传感器就装那边的T型槽）
2. 从螺丝配件包里找到 **T型螺母**（方形的扁螺母）
3. 把T型螺母从模组的**端头**滑入T型槽

```
  T型螺母怎么塞进T型槽：

  方法1：从端头滑入（端头没被堵住的情况）

  T型螺母 → ■■■ ──滑进去──→ ═══════════ 铝型材T型槽

  方法2：从侧面旋转塞入（端头被电机笼挡住的情况）

  把T型螺母竖着（转90°）从槽口塞进去，塞进去后再转回来卡住

       竖着塞进去        转回来卡住
          ■                ■■■
          ■              ──┘   └──
       ──┐↓┌──           ─────────
       ──┘ └──
```

4. 每根模组需要塞 **3颗** T型螺母（对应3个传感器座），先把3颗都塞进去
5. 拿一个**黑色安装座**，大孔朝向T型槽
6. 用螺丝穿过安装座的**大孔**，拧进T型槽里的T型螺母

```
  安装后的样子（从正面看）：

  黑色安装座
  ○────────○  ← 小孔（后面固定传感器用）
  │        │
  │   ●    │  ← 大孔里穿着螺丝
  └───┼────┘
      │
  ────┼──────── 铝型材外壁
      │
  ┌───┼────┐
  │   ■    │  ← T型螺母在T型槽里面，被螺丝拧住
  └────────┘
```

7. **先不要拧死！** 安装座需要能沿着T型槽左右滑动，后面要调位置

> 需要装多少个安装座？
> - Y轴：3个（装在其中1根Y轴模组上就行，两根Y轴滑块是同步的）
> - X轴：3个
> - Z轴：3个
> - **共9个安装座，9颗T型螺母**

---

### 步骤 11.4：把传感器固定到黑色安装座上

1. 拿一个 DS-ES61 传感器（黑色U形的那个）
2. 观察传感器底部，有2个小螺丝孔
3. 把传感器放到黑色安装座上面，传感器底部的2个孔对准安装座的2个小孔
4. 用小螺丝把传感器拧到安装座上

```
  传感器装到安装座上（从侧面看）：

  ┌──┐  ┌──┐
  │  │  │  │ ← 传感器U形缺口（感应片的小舌头要穿过这里）
  │  └──┘  │
  │ 传感器  │
  └──┬──┬──┘
     ○  ○  ← 小螺丝（传感器固定到安装座）
  ┌──┴──┴──┐
  │ 安装座  │
  └────●───┘
       │
    铝型材T型槽
```

5. **关键：U形缺口的开口方向**

```
  正确 ✓（缺口朝向感应片能穿进来的方向）：

  ← 滑块移动方向 →

     感应片的小舌头
           │
  ┌──┐  ┌──┤
  │  │  │  │← 感应片穿入U形缺口
  │  └──┘  │
  │ 传感器  │
  └────────┘

  错误 ✗（缺口方向反了，感应片进不去）：

  ← 滑块移动方向 →

     感应片的小舌头
           │
           │  ┌────────┐
           │  │ 传感器  │
           ×  │  ┌──┐  │  ← 缺口朝着别的方向，感应片穿不进去
              │  │  │  │
              └──┘  └──┘
```

6. 用手推滑块，让感应片的小舌头慢慢靠近传感器
7. 小舌头应该能**顺畅地穿过U形缺口的中间**，不碰到两侧
8. 如果碰到了：
   - 上下碰 → 调整安装座在T型槽上的位置（松开螺丝滑动安装座）
   - 左右碰 → 调整感应片在滑块上的位置（松开螺丝，利用长条孔微调）

---

### 步骤 11.5：确定3个传感器的大致位置

**每个轴上3个传感器的位置安排**：

```
  模组全长
  ├───────────────────────────────────────────────────┤

  行程范围
       ├────────────────────────────────────────┤

  [负限位]  [原点]                            [正限位]
     ↓       ↓                                   ↓
  ===U=======U===================================U=== 模组
  ↑  ↑       ↑                                   ↑  ↑
  端头│      │                                   │端头
     │      └ 紧挨负限位内侧约10-20mm            │
     │                                           │
     └ 距离端头约10mm                    距离端头约10mm
       （滑块能到达的最远位置再往外一点） （同理）
```

具体操作：

1. 把滑块**推到行程的一端**（推到推不动为止）
2. 看感应片现在在什么位置
3. 把**负限位传感器**放在感应片位置**再往外5-10mm**的地方（确保滑块到极限位置之前就能触发）
4. 把**原点传感器**放在负限位**内侧10-20mm**的地方
5. 把滑块**推到行程的另一端**
6. 把**正限位传感器**放在感应片位置**再往外5-10mm**的地方

**Y轴**、**X轴**、**Z轴**都按这个方法装。

---

### 步骤 11.6：逐一检查每个轴

装完后，手动推滑块从一端到另一端，检查：

**Y轴检查**：
- [ ] 滑块推到最前 → 感应片穿过负限位传感器的U形缺口 ✓
- [ ] 继续往回推约10-20mm → 感应片穿过原点传感器 ✓
- [ ] 滑块推到最后 → 感应片穿过正限位传感器 ✓
- [ ] 全程感应片不碰传感器，顺畅穿过 ✓

**X轴检查**：同上

**Z轴检查**：同上（注意Z轴是上下方向）

---

### 步骤 11.7：整理传感器的线

每个传感器拖着约2米长的线，9个传感器就是9根线，容易缠成一团。

1. 把同一个轴的3根传感器线**捆在一起**（用扎带）
2. 沿着铝型材的槽走线，用扎带每隔15-20cm固定一次
3. 所有线最终汇集到你打算放驱动器和控制板的位置
4. 线不能碰到运动部件（滑块、同步带），否则会被夹断

```
  走线示意（俯视图）：

        传感器线沿铝型材走
           ↓↓↓
  ═══════╤═══╤═══╤═══════ Y轴模组
         │   │   │
         └───┴───┴──→ 汇集到控制板区域
```

> **传感器的精确位置不用现在就完美**，后面软件调试时还会微调。现在主要是：
> 1. 感应片装好了
> 2. 传感器装上了且方向对
> 3. 感应片能穿过U形缺口
> 4. 线整理好不碍事

---

## 十二、组装完成后的检查

### 整体检查清单

- [ ] **外观检查**：从正面、侧面、上方看龙门架，结构是否端正、不歪斜
- [ ] **Y轴检查**：前后推动Y轴，两侧滑块同步移动，带着X轴横梁一起平稳移动
- [ ] **X轴检查**：左右推动X轴滑块，在横梁上左右平滑移动
- [ ] **Z轴检查**：上下推动Z轴滑块，平滑上下移动
- [ ] **螺丝检查**：逐一检查所有螺丝是否拧紧（联轴器的紧定螺钉特别容易漏）

- [ ] **光电开关**：9个开关都安装好，感应片能经过对应的U形缺口

## 十三、常见问题

### Q：滑块推起来很紧/很涩怎么办？

这是正常的，新模组的滑块可能需要磨合。可以来回推动几十次让它顺滑起来。如果特别紧，检查模组有没有被挤压或安装时拧得过紧导致变形。

### Q：联轴器拧紧了但还是打滑怎么办？

确保轴完全插入到联轴器的底部，紧定螺钉要对准轴上的平面（如果有的话）。如果还是打滑，可能需要拧得更紧一些。

### Q：螺丝找不到对应的怎么办？

试着用不同大小的螺丝比对螺丝孔。一般模组用的是 M4 或 M5 的螺丝（M后面的数字就是直径毫米数）。如果配件包里确实缺少，五金店或淘宝都能买到。

### Q：L型板装上去后X轴是歪的怎么办？

松开L型板的螺丝，调整L型板在Y轴滑块上的位置，确保两块L型板的安装面在同一高度上。可以把X轴模组先放上去比划着调。

### Q：Z轴的滑块一松手就掉下去？

这是正常的！因为有重力。等接通电机和驱动器后，带刹车的电机上电时刹车会抱紧，就不会掉了。组装阶段可以用手扶着或者把Z轴滑块推到最下面。

### Q：我不确定某个零件装在哪里？
