## 十四、第九阶段：认识电控系统（接线前必读）

> 在动手之前，先花5分钟搞明白我们要做什么。看不懂没关系，后面每一步都会手把手教。

### 14.1 电控系统是什么

机械部分让龙门架能"动"，电控部分让龙门架"听话地动"。

整个电控系统就像一条指挥链：

```
你写的程序（Arduino代码）
    ↓ 发出指令（脉冲信号）
Arduino 控制板
    ↓ 通过杜邦线发送脉冲
驱动器（3个，每个电机一个）
    ↓ 把小信号放大成大电流
电机（3个）
    ↓ 转动
龙门架移动

同时：
传感器（9个）
    ↓ 检测到滑块位置
Arduino 控制板
    ↓ 根据传感器反馈做出判断
停止或继续运动
```

用一个比喻：
- **Arduino** = 你的大脑（发号施令）
- **驱动器** = 你的手臂肌肉（执行命令、提供力量）
- **电机** = 你的手指（做具体的动作）
- **传感器** = 你的眼睛（看到位置信息反馈给大脑）
- **电源** = 食物（给所有人提供能量）

### 14.3 认识驱动器上的接口

拿起一个驱动器（2HSS57-C），你会看到有接线端子的那一面有好几排绿色小方块。

**什么是接线端子**：就是那些绿色的小方块。每个方块里有一个小孔和一颗小螺丝。你用小一字螺丝刀把螺丝拧松，把剥好皮的电线头插进小孔里，再拧紧螺丝把线夹住。

```
怎么往接线端子里插线：

  1. 拧松螺丝      2. 插入电线      3. 拧紧螺丝

   ╔══╗            ╔══╗            ╔══╗
   ║↺║            ║  ║            ║↻║
   ╠══╣            ╠══╣            ╠══╣
   ║  ║ ←孔是空的  ║══║ ←线插进去  ║██║ ←线被夹紧了
   ╚══╝            ╚══╝            ╚══╝

  拧松后孔会张开    线头插进去      拧紧后线就固定住了
  （逆时针转2-3圈） （露出的铜线）  （顺时针拧紧）
```

## 十五、第十阶段：设置驱动器拨码开关

> 在接线之前，先把3个驱动器的拨码开关拨好。这一步不需要通电，用手指或者小工具拨就行。

### 15.1 找到拨码开关

在驱动器侧面（有散热片的那一面），你会看到一排 **蓝色的小拨动开关**，标记为 SW1~SW8。

> 参考实物照片：`设备信息/photo_2026-03-16_16-14-32.jpg`

旁边还有一个白色的4针端子（刹车/到位端口）和一个 Micro-USB 口（调参用的，暂时不管）。

每个开关只有两个位置：**ON**（向下拨，靠近 "ON" 字样的方向）和 **OFF**（向上拨）。

你的驱动器出厂时**所有开关都是OFF**（白色拨片全部朝上），和照片里看到的一样。

驱动器正面的标签纸上印着细分拨码对照表，可以对照着看。

```
蓝色拨码开关实物（侧面看）：

         ↑ 向上 = OFF（出厂默认，白色拨片朝上）

  ┌─────────────────────────────────┐
  │ □ □ □ □ ■ ■ □ ■               │  ← 我们要设成这样
  │ 1  2  3  4  5  6  7  8   ON   │
  └─────────────────────────────────┘

         ↓ 向下 = ON（朝 "ON" 字样方向拨）

  □ = OFF 位置（白色拨片朝上，出厂默认）
  ■ = ON 位置（白色拨片朝下，拨向 "ON" 字样）

  需要把 SW5、SW6 向下拨到 ON，其余保持 OFF
```

### 15.2 每个开关是干什么的

| 开关 | 作用 | 我们要设成 | 为什么 |
|------|------|---------|--------|
| SW1 | 伺服模式选择 | **OFF** | OFF = 脉冲/方向控制模式，这是 Arduino 控制用的模式 |
| SW2 | 电机旋转方向 | **OFF** | OFF = 默认方向(CCW)，后面发现方向反了再改 |
| SW3 | 细分设置 第1位 | **OFF** | 和 SW4/5/6 配合，设成 3200 细分 |
| SW4 | 细分设置 第2位 | **OFF** | 和 SW3/5/6 配合，设成 3200 细分 |
| SW5 | 细分设置 第3位 | **ON** | 和 SW3/4/6 配合，设成 3200 细分 |
| SW6 | 细分设置 第4位 | **ON** | 和 SW3/4/5 配合，设成 3200 细分 |
| SW7 | 脉冲平滑 | **OFF** | 先关闭，后面需要再开 |
| SW8 | 开环/闭环模式 | **OFF** | OFF = 闭环模式（DB9 编码器已连接，位置更准确） |

### 15.3 什么是"细分"？简单说一下

细分越高，电机转得越细腻越平滑，就像视频帧率越高越流畅。

我们设 **3200 细分**，意思是电机转一整圈需要 3200 个脉冲信号。

对于我们的龙门架（GT2同步带，20齿带轮）：
- 带轮一圈走 40mm
- 3200 个脉冲走 40mm
- 每个脉冲走 40 ÷ 3200 = **0.0125mm = 12.5微米**

12.5微米的精度，对旋涂来说完全够用了。

### 15.4 动手设置

**3个驱动器都要设成完全一样的！**

```
我们的设置（3个驱动器全部一样）：

         ↑ 向上 = OFF

  ┌─────────────────────────────────┐
  │ □  □  □  □  ■  ■  □  ■        │
  │ 1   2   3   4   5   6   7   8  │  ON
  └─────────────────────────────────┘

         ↓ 向下 = ON

  SW1=OFF（上）✓ （脉冲模式）
  SW2=OFF（上）✓ （默认方向）
  SW3=OFF（上）✓ ┐
  SW4=OFF（上）✓ ├ 51200 脉冲/转 → 682.67 步/mm（导程 75mm）
  SW5=OFF（上）✓ ├
  SW6=ON （下）✓ ┘
  SW7=OFF（上）✓ （不平滑）
  SW8=OFF（上）✓ （闭环模式，DB9编码器已连接）
```

> **SW8 已改为 OFF**：DB9 编码器已接好，现在运行在闭环模式，位置追踪更准确、不丢步。

操作步骤：
1. 拿起第1个驱动器
2. 找到侧面的蓝色拨码开关（一排8个小白色拨片）
3. 把 **SW5、SW6 向下拨**（朝 "ON" 方向），其余保持 OFF（朝上）
4. 用手指或笔尖拨
5. 设好后对照上面的图再检查一遍
6. 第2个、第3个驱动器同样设置

### 15.5 给驱动器贴标签

趁现在方便，给3个驱动器贴上标签：
- 驱动器1 → 贴标签写 **"Y轴驱动器"**
- 驱动器2 → 贴标签写 **"X轴驱动器"**
- 驱动器3 → 贴标签写 **"Z轴驱动器"**

> 后面接线的时候不容易搞混。

## 十六、第十一阶段：接电机线到驱动器

> 这是接线的第一步。把每个电机的线接到对应的驱动器上。
> **全程不要通电！电源插头不要插到墙上！**

### 16.1 准备工作

> 参考实物照片：
> - 驱动器正面（端子标签）：`设备信息/photo_2026-03-16_16-14-28.jpg`
> - 电机铭牌（线色定义）：`设备信息/photo_2026-03-09_23-25-47.jpg`

1. 准备好 **剥线钳** 和 **小一字螺丝刀**
2. 把3个贴好标签的驱动器放在龙门架旁边
3. 确认哪个电机是哪个轴的（之前组装时应该已经装好了）
4. **看一眼驱动器正面的标签**——上面印着所有端子的名称和位置，接线时对照着看

### 16.2 认识电机上的线

> 参考实物照片：
> - 电机线缆全貌：`设备信息/photo_2026-03-09_23-25-55.jpg`
> - 电机铭牌（线色定义）：`设备信息/photo_2026-03-09_23-25-47.jpg`

每个电机背面出来**一根粗黑色电缆**，这根电缆分成 **2~3组**：

```
电机背面出来的线（实物）：

  ┌───────┐
  │ 电 机 │
  └───┬───┘
      │
    粗黑色电缆
      │
      ├──→ ① 4根彩色线（红/蓝/绿/黑）     ← 电机相线
      │      线头已经剥好，露出铜线
      │      直接插到驱动器螺丝端子里
      │
      ├──→ ② 一个黑色DB9接头（长方形插头） ← 编码器接口
      │      这是一个插头，不是散线！
      │      需要用"DB9免焊接头"转接（后面说）
      │
      └──→ ③ 2根细线（红+黑）              ← 刹车线（只有Z轴电机有）
             另外两个电机没有这2根线
```

**① 电机相线（4根彩色线，线头已经剥好露出铜线）**

```
线色对应关系（电机铭牌上写的 MOTOR LEADS）：

  红色线 → A+（电机A相正）
  蓝色线 → A-（电机A相负）
  绿色线 → B+（电机B相正）
  黑色线 → B-（电机B相负）

  口诀记忆：红蓝一对是A相，绿黑一对是B相
```

**② 编码器接口（DB9公头插头）**

编码器不是散线，而是一个 **DB9 公头插头**（黑色长方形外壳，前面有金属针脚）。

```
DB9 公头插头长这样（正面看）：

  ┌─────────────┐
  │ ● ● ● ● ● │  ← 上排5根针（针脚1~5）
  │  ● ● ● ●  │  ← 下排4根针（针脚6~9）
  └─────────────┘

  针脚编码器信号定义（电机铭牌上写的 ENCODER LEADS DB9）：
  针脚1 = GND  / 0V    （编码器地线）
  针脚2 = VCC  / +5V   （编码器电源）
  针脚3 = A+           （编码器A相正）
  针脚4 = A-           （编码器A相负）
  针脚5 = B+           （编码器B相正）
  针脚6 = B-           （编码器B相负）
  针脚7~9 = 没有使用
```

**⚠️ 这个DB9插头不能直接插到驱动器上！** 驱动器的编码器端口是螺丝端子，不是DB9插座。你需要买一个 **"DB9 免焊接头（母头）"** 来转接（淘宝约4元/个，需要3个）。后面 16.5 会详细说怎么用。

**③ 刹车线（只有Z轴电机有，另外2个电机没有）**

Z轴电机多出来的 2根细线（红+黑），后面接 DSTUR-T80 USB继电器 CH2（见第二十一阶段），现在先用胶带包好放一边。

### 16.3 剥线

电机的线头如果已经露出铜线了（亮亮的金属丝），就不用剥了。如果线头是包着绝缘皮的，需要用剥线钳剥掉约 **5-8mm**。

```
剥线步骤：

  1. 找到剥线钳上对应线径的刻度口
     粗线（电机相线）：大约用 AWG18~20 的孔
     细线（编码器线）：大约用 AWG24~26 的孔
     不确定用哪个？从大孔到小孔试，能剥掉皮又不伤铜线的就是对的

  2. 把线头伸进剥线钳的刻度口，露出约 5-8mm
  3. 握紧剥线钳的把手
  4. 往外轻轻一拉

  剥之前：
  ════════════╗
              ║ ← 绝缘皮包着
  ════════════╝

  剥之后：
  ════════╗
          ╠════ ← 露出的铜线（5-8mm，亮亮的）
  ════════╝
```

### 16.4 接电机相线到驱动器（粗线4根）

以 **Y轴** 为例（X轴、Z轴完全一样的操作）：

1. 找到 Y轴电机 背面出来的 **4根彩色线**（红蓝绿黑）
2. 找到标记为 **"Y轴驱动器"** 的驱动器
3. 找到驱动器上的 **功率端口**（底部那排8个端子）
4. 看端子标签：从左到右是 `(-) (+) AC2 AC1 B- B+ A- A+`
5. 电机线接**右边4个**（A+ A- B+ B-），24V电源接**左边2个** `(+)` `(-)`，AC1 AC2 不接

逐根接线：

```
在功率端口那排端子上，找到右边标着 A+ 的端子：

第1根：红色线 → A+ 端子（最右边）

  ① 拿起小一字螺丝刀
  ② 对准 A+ 端子上面的小螺丝，逆时针转2-3圈（拧松）
  ③ 把红色电机线的铜线头插进端子的小孔里
     铜线要全部进去，不要有铜线露在外面
  ④ 顺时针拧紧螺丝，把线夹紧
  ⑤ 用手轻轻拉一下线，确认拉不出来 → 接好了！

第2根：蓝色线 → A- 端子（A+左边）→ 同样操作
第3根：绿色线 → B+ 端子（A-左边）→ 同样操作
第4根：黑色线 → B- 端子（B+左边）→ 同样操作
```

接完后确认：

```
Y轴驱动器 功率端口（从左到右看）：

  ┌────┬────┬────┬────┬────┬────┬────┬────┐
  │ (-)│ (+)│AC2 │AC1 │ B- │ B+ │ A- │ A+ │
  │ 空 │ 空 │ 空 │ 空 │ 黑 │ 绿 │ 蓝 │ 红 │
  └────┴────┴────┴────┴────┴────┴────┴────┘
   ↑    ↑    不接  不接  ↑    ↑    ↑    ↑
   后面接     (交流       电机相线（4根彩色线）
   24V电源    供电不用)

  口诀：红A蓝A绿B黑B
  AC1、AC2 不接！那是交流供电用的，我们用直流24V。
```

### 16.5 接编码器到驱动器（通过DB9免焊接头）

> **⚠️ 这一步需要你买了 "DB9免焊接头（母头）" 之后才能做！**
> 如果还没买，先跳过这一步，先把电机相线（16.4）和电源线（第十二阶段）接好。
> 淘宝搜 **"DB9 免焊接头 母头"**，约4元/个，买3个。

编码器是通过 DB9 插头连接的，不是散线。我们需要用 **DB9 免焊接头** 把 DB9 信号转成可以接到驱动器螺丝端子的裸线。

**DB9免焊接头长什么样**：

```
  正面：DB9 母口（9个孔）        背面/侧面：螺丝端子
  ┌─────────────┐               ┌─────────────┐
  │ ○ ○ ○ ○ ○ │               │ ①②③④⑤      │  ← 每个针脚对应一个螺丝端子
  │  ○ ○ ○ ○  │               │  ⑥⑦⑧⑨      │
  └─────────────┘               └─────────────┘

  电机的DB9公头   → 插到这个母口里
  背面的螺丝端子  → 用短线接到驱动器的编码器端口
```

**操作步骤**：

```
  第一步：把电机的 DB9 公头插到免焊接头的母口里
         （对准针脚插进去，拧紧两边的螺丝固定住）

  第二步：准备6小段杜邦线（剪掉两头接头，只留中间的裸线，两头各剥5mm）

  第三步：从免焊接头的螺丝端子引线到驱动器的编码器端子

         免焊接头端子号    信号      驱动器编码器端口
         ─────────────────────────────────────────
         端子① (Pin1)   → GND   → 驱动器 GND（端子6）
         端子② (Pin2)   → +5V   → 驱动器 VCC（端子5）
         端子③ (Pin3)   → A+    → 驱动器 PA+（端子3）
         端子④ (Pin4)   → A-    → 驱动器 PA-（端子4）
         端子⑤ (Pin5)   → B+    → 驱动器 PB+（端子1）
         端子⑥ (Pin6)   → B-    → 驱动器 PB-（端子2）
         端子⑦⑧⑨       → 没用，不接
```

```
  接完后的样子：

  电机 ──DB9公头──→ [DB9免焊接头] ──6根短线──→ 驱动器编码器端口
                     ↑                           ↑
                   电机插头插到这里          短线接到这里的螺丝端子
```

**简化对照表**（免焊接头端子 → 驱动器编码器端子）：

| 免焊接头 Pin | 信号 | 驱动器编码器端子 |
|-------------|------|----------------|
| Pin 1 | GND | GND（端子6） |
| Pin 2 | +5V/VCC | VCC（端子5） |
| Pin 3 | A+ | PA+（端子3） |
| Pin 4 | A- | PA-（端子4） |
| Pin 5 | B+ | PB+（端子1） |
| Pin 6 | B- | PB-（端子2） |

> **注意**：免焊接头上的端子编号通常印在接头壳上（很小的数字），仔细看。
> 如果看不清编号，DB9 的针脚排列是固定的：上排从左到右是 1-2-3-4-5，下排是 6-7-8-9。

### 16.6 三个轴都接完

**Y轴电机 → Y轴驱动器** ✅ （4根相线 + DB9编码器）

**X轴电机 → X轴驱动器** ← 完全一样的操作

**Z轴电机 → Z轴驱动器** ← 完全一样的操作

### 16.7 Z轴电机的刹车线（先不接）

Z轴的电机比另外两个多出来 **2根线**（通常是红色和黑色的一对细线），这是 **刹车线**。

**现在不要接这2根线！** 后面接 DSTUR-T80 USB继电器 CH2（见第二十一阶段）。

把这2根线：
1. 用胶带把裸露的铜线头包起来（防止碰到别的线短路）
2. 标记上 "Z轴刹车线"
3. 绑好放到一边

- [ ] Y轴：4根相线（红→A+ 蓝→A- 绿→B+ 黑→B-）✓
- [ ] Y轴：DB9编码器通过免焊接头接到编码器端口（6根短线）✓
- [ ] X轴：同上 ✓
- [ ] Z轴：同上 ✓
- [ ] Z轴刹车线（2根红+黑）已用胶带包好放一边 ✓
- [ ] 每根线都拉一下确认不会脱落 ✓

## 十七、第十二阶段：接电源到驱动器

> **⚠️ 安全提醒**：接电源线的时候，电源的插头**绝对不能插在墙上的插座里**！
> 先把所有线接好，检查完毕，最后一步才插电。

### 17.1 接24V输出到3个驱动器

我们需要把24V电源的 +V（正极）和 -V（负极）分别接到3个驱动器的 **(+)** 和 **(-)** 端子上。

3个驱动器共用同一个电源，这叫 **"并联"**，就像一个插线板同时给3个手机充电。

> **⚠️ 注意**：驱动器上的24V电源端子标签是 `(+)` 和 `(-)`，不是VCC和GND！
> VCC和GND 在编码器端口上，那是给编码器供电的5V，不要搞混！

```
接线示意图：

                         ┌→ Y轴驱动器 功率端口 (+) 端子
  24V电源 +V ────红线───┼→ X轴驱动器 功率端口 (+) 端子
                         └→ Z轴驱动器 功率端口 (+) 端子

                         ┌→ Y轴驱动器 功率端口 (-) 端子
  24V电源 -V ────黑线───┼→ X轴驱动器 功率端口 (-) 端子
                         └→ Z轴驱动器 功率端口 (-) 端子
```

### 17.2 怎么一个电源接3个驱动器？

电源的 V+ 只有2个端子孔，但我们要接3根线出去。方法如下：

**方法（推荐）：拧线法**

1. 先准备 **6段电线**（每段约 20-30cm 长）：
   - 3段用红色线（或任何暖色）→ 正极
   - 3段用黑色线（或任何冷色）→ 负极
   - **线从哪来？** 从杜邦线里拆！取6根杜邦线，用剪刀把两头的塑料接头剪掉，只留中间的电线。两头各剥出 5-8mm 铜线

2. 接正极（V+）：

```
  步骤①：把3根红色线的一头的铜线拧在一起（3股拧成1股）

           线1 ──╲
           线2 ───╳── 3根铜线拧在一起
           线3 ──╱

  步骤②：把拧好的这一大股插进电源 +V 的端子里，拧紧螺丝
          （+V有2个端子孔，用哪个都行，也可以2个孔各塞一些）

  步骤③：3根红色线的另一头分别接到3个驱动器的 (+) 端子

           ┌── 红线1 ──→ Y轴驱动器 功率端口 (+)
  电源 +V ─┼── 红线2 ──→ X轴驱动器 功率端口 (+)
           └── 红线3 ──→ Z轴驱动器 功率端口 (+)
```

3. 接负极（-V）：**完全一样的方法**，3根黑色线拧在一起接 -V，另一头分别接3个驱动器的 **(-)** 端子

### 17.3 接220V输入（先不插电）

你的电源是 MAVN S-360-24，220V输入端子在**右边**（L、N、⏚ 三个端子）。

> 参考实物照片：`设备信息/photo_2026-03-16_16-14-35.jpg`

你需要一根**带插头的电源线**（三芯线，一头是三脚插头，另一头是3根裸线）。如果电源没有配这根线，可以用电脑主机的电源线剪一根，或者淘宝买一根"三芯电源线 带插头"。

接法（端子在电源**右边**）：
- 棕色线（或红色）→ **L** 端子（最右边，火线）
- 蓝色线 → **N** 端子（中间，零线）
- 黄绿色线 → **⏚** 端子（左边那个，地线）

```
电源右边的3个端子（面对你看）：

  ⏚     N     L
  ○     ○     ○
  ↑     ↑     ↑
  黄绿   蓝    棕
  (地线) (零线) (火线)
```

> **现在不要插电！** 后面还有检查步骤。
> **不要动 +V ADJ 旋钮！** 那是微调电压用的，出厂已经调好24V了。

### 17.4 自检清单

```
24V电源 V+ ──→ X轴驱动器 功率端口 (+)  ✓
24V电源 V+ ──→ Y轴驱动器 功率端口 (+)  ✓
24V电源 V+ ──→ Z轴驱动器 功率端口 (+)  ✓

24V电源 V- ──→ X轴驱动器 功率端口 (-)  ✓
24V电源 V- ──→ Y轴驱动器 功率端口 (-)  ✓
24V电源 V- ──→ Z轴驱动器 功率端口 (-)  ✓

220V输入线已接好  ✓
电源插头没有插到墙上  ✓

正极（V+/VCC）和负极（V-/GND）没有接反  ✓
```

## 十八、第十三阶段：安装 Arduino IDE（在电脑上操作）

> 现在暂时离开龙门架，到电脑上操作。

### 18.1 什么是 Arduino IDE

Arduino IDE 是一个免费的电脑软件，用来：
1. 写控制程序（代码）
2. 把程序上传到 Arduino 板子里
3. 看 Arduino 传回来的数据（叫"串口监视器"）

IDE 是 "集成开发环境" 的缩写，但你不用管这个名字，就理解为"写代码的软件"。

### 18.2 下载和安装

**你的电脑是 Mac**，按以下步骤操作：

1. 打开浏览器（Safari/Chrome都行）
2. 搜索 **"Arduino IDE 下载"** 或直接访问 Arduino 官网的下载页面
3. 选择 **macOS** 版本（如果你的Mac是M1/M2/M3/M4芯片选 Apple Silicon 版，Intel芯片选 Intel 版）
   - 不知道自己是什么芯片？点左上角苹果 →"关于本机"→ 看"芯片"那一行
4. 下载完是一个 `.dmg` 文件，双击打开
5. 把 Arduino IDE 的图标**拖到** Applications（应用程序）文件夹里
6. 打开 Arduino IDE

> **第一次打开可能弹出安全提示**："无法打开，因为无法验证开发者"
> 解决方法：去 系统设置 → 隐私与安全性 → 往下翻找到提示信息 → 点 "仍要打开"

### 18.2.1 安装 CH340 驱动（重要！你的Arduino需要这步）

> 参考实物照片：`设备信息/photo_2026-03-16_16-14-22.jpg`

从照片看，你的 Arduino Mega 是国产版本，使用 **CH340 芯片**（而不是官方版的 ATmega16U2）。这意味着你的电脑需要安装 CH340 驱动才能识别这块板子。

**安装步骤**：

1. 打开浏览器，搜索 **"CH340 驱动 Mac 下载"**
2. 下载 CH340 的 Mac 驱动程序（通常是一个 `.pkg` 安装包）
3. 双击安装，按提示一路点下一步
4. 安装完成后**重启电脑**
5. 重启后把 Arduino 用 USB 线插到电脑上
6. 打开 Arduino IDE → 工具 → 端口，应该能看到 `/dev/cu.wchusbserialXXXX` 之类的端口了

> 如果不安装这个驱动，Arduino IDE 里的端口列表会是空的，什么都选不了。
> 这是国产 Arduino 板子最常见的坑，驱动装好就没问题了。

### 18.3 用 USB 线连接 Arduino

1. 找到 Arduino Mega 板子上的 USB 口（大的方形 USB-B 口，和打印机线一样的）
2. 用 USB 线（通常 Arduino 包装盒里会配一根）连接：
   - USB-B 端 → 插 Arduino 板子
   - USB-A 端 → 插电脑（如果你的Mac只有Type-C口，需要一个转接头）
3. 插上后 Arduino 板子上应该有一个 LED 灯亮了 → 说明供电正常

### 18.4 配置 Arduino IDE（重要！）

打开 Arduino IDE 后：

**第一步：选择板子类型**

1. 在菜单栏点 **工具 (Tools)** → **开发板 (Board)**
2. 如果看到 **"Arduino Mega or Mega 2560"** 就直接点它
3. 如果看不到，需要先安装：
   - 点 工具 → 开发板 → 开发板管理器
   - 搜索 "Arduino AVR Boards"
   - 点安装
   - 安装完再去 工具 → 开发板 → 选 "Arduino Mega or Mega 2560"

**第二步：选择端口**

1. 点 **工具 (Tools)** → **端口 (Port)**
2. 你会看到类似这样的选项：
   - `/dev/cu.usbmodem14201 (Arduino Mega or Mega 2560)`
   - 或 `/dev/cu.usbserial-XXXX`
3. 选那个**带 Arduino 名字的**，或者带 "usbmodem" / "usbserial" 的

> 如果端口列表是空的或者看不到 Arduino：
> - 检查 USB 线插紧了没有
> - 换一根 USB 线试试（有些 USB 线只能充电不能传数据！）
> - 如果你的 Arduino 是国产版本，可能需要安装 CH340 驱动（搜索"CH340驱动 Mac"下载安装）

**第三步：测试连接——上传 Blink 示例**

这是验证 Arduino 连接是否正常的标准方法：

1. 点 **文件 (File)** → **示例 (Examples)** → **01.Basics** → **Blink**
2. 会打开一个新窗口，里面有一段示例代码（不用改任何东西）

**如果 LED 在闪 → 恭喜！Arduino 连接成功！你可以控制它了！**

> 如果上传失败（报错）：
> - 确认 "开发板" 选的是 Arduino Mega
> - 确认 "端口" 选对了
> - 确认 USB 线插紧了
> - 把 Arduino 拔掉重插，再试一次

## 十九、第十四阶段：接 Arduino 信号线到驱动器

> 现在要把 Arduino 和驱动器连起来，让 Arduino 能控制电机转动。
> **操作前确保24V电源已关闭（插头没插到墙上）！**

### 19.1 控制原理（30秒快速理解）

Arduino 控制电机只靠两种信号：

- **PLS（脉冲）**：Arduino 快速地发出"开-关-开-关"的电信号。每"开关"一次，电机就转一小步。发得越快，电机转得越快。
- **DIR（方向）**：Arduino 给一个高电平（5V）= 正转，给低电平（0V）= 反转。

就像打节拍器：
- 节拍器打一下 = 电机转一小步
- 节拍器打得快 = 电机转得快
- 你可以选择让它顺时针或逆时针

### 19.2 接线方式说明

我们使用 **"共阳极"** 接法（驱动器手册推荐的方式）：
- Arduino 的 **5V** 引脚 → 接到所有驱动器的 **PLS+** 和 **DIR+**（这是公共正极）
- Arduino 的 **数字引脚** → 接到驱动器的 **PLS-** 和 **DIR-**（每个轴2根）
- **ENA+** 和 **ENA-** → **不接**（悬空就好，不需要使能控制）

### 19.3 准备杜邦线

从杜邦线包里拆出 **12根** 杜邦线（公对母）。建议用不同颜色方便区分，比如：
- 红色 × 若干 → 用于 5V 正极线
- 其他颜色 × 6根 → 用于6根信号线（每个轴2根）

**杜邦线的两头**：
```
  公头（针）              母头（孔）
  ──────●                ──────□

  公头插到 Arduino        母头这端要处理一下才能接到驱动器
  的引脚孔里              （下面说怎么处理）
```

### 19.4 杜邦线怎么接到驱动器端子上？

驱动器的端子是螺丝夹线的，需要裸铜线才能插进去。杜邦线的母头（塑料方孔）插不进端子。

**处理方法**：

```
  方法：把杜邦线的母头那端剪掉，剥出铜线

  ① 原始的杜邦线：
     公头 ●────────────────────□ 母头

  ② 用剪刀把母头剪掉：
     公头 ●────────────────╗
                           ╚══ 剪掉

  ③ 用剥线钳剥掉5-8mm绝缘皮：
     公头 ●────────────════   ← 露出铜线

  现在公头那端插 Arduino，铜线那端插驱动器端子。
```

**12根杜邦线都这样处理**（只处理母头那端，公头那端保留不动）。

### 19.5 接线：5V正极线（公共线）

需要把 Arduino 的 5V 引脚接到 **6个端子**（3个驱动器的 PLS+ 和 DIR+）。

Arduino Mega 有 **2个 5V 引脚**，我们可以利用它们。

```
具体接法：

  准备6根杜邦线（处理好的），都用红色或橙色

  从 Arduino 5V 引脚1 出发（可以把2-3根杜邦线的公头并排挤进同一个引脚孔）：
  → 红线1 → X轴驱动器 控制信号端口 PLS+（端子1）
  → 红线2 → X轴驱动器 控制信号端口 DIR+（端子3）
  → 红线3 → Y轴驱动器 控制信号端口 PLS+（端子1）

  从 Arduino 5V 引脚2 出发（另一个5V引脚）：
  → 红线4 → Y轴驱动器 控制信号端口 DIR+（端子3）
  → 红线5 → Z轴驱动器 控制信号端口 PLS+（端子1）
  → 红线6 → Z轴驱动器 控制信号端口 DIR+（端子3）
```

> **小技巧**：如果一个引脚孔塞不下3根杜邦线，可以：
> - 把3根杜邦线的铜线端拧在一起，先塞进第一个驱动器的PLS+端子
> - 然后再从这个端子引出一根线到下一个驱动器
> - 像串糖葫芦一样一个接一个

### 19.6 接线：信号线（每个轴2根）

这6根线是最重要的——它们传递 Arduino 给电机的指令。

```
Arduino 引脚        →    驱动器端子
─────────────────────────────────────
D2（数字引脚2）     →    X轴驱动器 PLS-（控制信号端口 端子2）
D3（数字引脚3）     →    X轴驱动器 DIR-（控制信号端口 端子4）
D4（数字引脚4）     →    Y轴驱动器 PLS-（控制信号端口 端子2）
D5（数字引脚5）     →    Y轴驱动器 DIR-（控制信号端口 端子4）
D6（数字引脚6）     →    Z轴驱动器 PLS-（控制信号端口 端子2）
D7（数字引脚7）     →    Z轴驱动器 DIR-（控制信号端口 端子4）
```

操作步骤（以X轴为例）：

```
  第1根信号线（D2 → X轴 PLS-）：

  ① 拿一根处理好的蓝色杜邦线
  ② 把公头那端插到 Arduino 板子上标着 "2" 的引脚孔里
  ③ 把铜线那端插到 X轴驱动器 控制信号端口 的第2号端子（PLS-）里
  ④ 拧紧驱动器端子的螺丝

  第2根信号线（D3 → X轴 DIR-）：

  ① 另一根蓝色杜邦线
  ② 公头 → Arduino 引脚 "3"
  ③ 铜线 → X轴驱动器 控制信号端口 第4号端子（DIR-）
  ④ 拧紧

  Y轴：同样操作，用绿色杜邦线（D4 → PLS-，D5 → DIR-）
  Z轴：同样操作，用紫色杜邦线（D6 → PLS-，D7 → DIR-）
```

### 19.7 接完后的驱动器控制信号端口

```
每个驱动器的控制信号端口接完后应该是这样的：

  以X轴驱动器为例：

  ┌─────┬─────┬─────┬─────┬─────┬─────┐
  │PLS+ │PLS- │DIR+ │DIR- │ENA+ │ENA- │
  │  1  │  2  │  3  │  4  │  5  │  6  │
  │     │     │     │     │     │     │
  │红线 │蓝线 │红线 │蓝线 │ 空  │ 空  │
  │↑    │↑    │↑    │↑    │     │     │
  │来自  │来自  │来自  │来自  │不接  │不接  │
  │5V   │D2   │5V   │D3   │     │     │

  Y轴驱动器同理，但信号线是绿色（D4/D5）
  Z轴驱动器同理，但信号线是紫色（D6/D7）
  └─────┴─────┴─────┴─────┴─────┴─────┘
```

### 19.8 自检清单

- [ ] Arduino 5V → 所有驱动器 PLS+ 和 DIR+（共6根红杜邦线）✓
- [ ] Arduino D2 → X轴 PLS- ✓
- [ ] Arduino D3 → X轴 DIR- ✓
- [ ] Arduino D4 → Y轴 PLS- ✓
- [ ] Arduino D5 → Y轴 DIR- ✓
- [ ] Arduino D6 → Z轴 PLS- ✓
- [ ] Arduino D7 → Z轴 DIR- ✓
- [ ] ENA+ 和 ENA- 都没接线（空着）✓
- [ ] 每根线的驱动器端都拧紧了 ✓

## 二十、第十五阶段：接传感器到 Arduino

> 9个传感器（光电开关 DS-ES61）需要接到 Arduino 上。
> 每个传感器有3根线：棕色（电源+）、蓝色（电源-）、白色（信号）。

### 20.1 传感器接线原理

```
每个传感器3根线：

  棕色线 → 接 Arduino 的 5V（电源正极，给传感器供电）
  蓝色线 → 接 Arduino 的 GND（电源负极）
  白色线 → 接 Arduino 的一个数字引脚（传感器发出的信号从这里读取）

  9个传感器的棕色线全部接到 5V（并联）
  9个传感器的蓝色线全部接到 GND（并联）
  9个传感器的白色线各自接到不同的数字引脚
```

### 20.2 传感器引脚分配

```
传感器位置              →  Arduino 数字引脚
──────────────────────────────────────────
X轴 负限位传感器        →  D22
X轴 原点传感器          →  D23
X轴 正限位传感器        →  D24
Y轴 负限位传感器        →  D25
Y轴 原点传感器          →  D26
Y轴 正限位传感器        →  D27
Z轴 负限位传感器        →  D28
Z轴 原点传感器          →  D29
Z轴 正限位传感器        →  D30
```

### 20.3 接线方案：端子排中继 + 彩色杜邦线

我们不把 27 根传感器线全部直接拉到 Arduino，而是**每个轴用一小段端子排做中继**，在端子排上把 3 个传感器的电源线合并，只出 5 根线到 Arduino。这样更整洁、更可靠。

**杜邦线颜色规范**（和电机信号线颜色一致，方便识别）：

```
  X轴信号线：蓝色杜邦线 × 3（和X轴电机信号线同色）
  Y轴信号线：绿色杜邦线 × 3（和Y轴电机信号线同色）
  Z轴信号线：紫色杜邦线 × 3（和Z轴电机信号线同色）
  5V 电源线：红色杜邦线
  GND 地线：黑色杜邦线
```

### 20.4 每个轴的端子排接法

每个轴切一小段端子排（5位），按下图接线：

```
  端子排（以X轴为例，5个端子位）：

  端子位:   ①      ②      ③      ④       ⑤
  用途:    信号1   信号2   信号3   5V共用   GND共用
          (负限位) (原点)  (正限位)

  传感器侧（拧进端子排）：
  传感器1:  白→①                  棕→④    蓝→⑤
  传感器2:         白→②           棕→④    蓝→⑤
  传感器3:                白→③    棕→④    蓝→⑤
                                   ↑        ↑
                          3根棕色线拧进同一个端子  3根蓝色线拧进同一个端子

  Arduino侧（杜邦线从端子排出发到Arduino）：
  ① → 蓝色杜邦线 → Arduino D22（X轴负限位）
  ② → 蓝色杜邦线 → Arduino D23（X轴原点）
  ③ → 蓝色杜邦线 → Arduino D24（X轴正限位）
  ④ → 红色杜邦线 → Arduino 5V
  ⑤ → 黑色杜邦线 → Arduino GND
```

三个轴都这样做：

| 轴 | 端子①→Arduino | 端子②→Arduino | 端子③→Arduino | 端子④ | 端子⑤ | 杜邦线颜色 |
|----|-------------|-------------|-------------|-------|-------|----------|
| X轴 | D22（负限位）| D23（原点）| D24（正限位）| 5V | GND | **蓝色** × 3 |
| Y轴 | D25（负限位）| D26（原点）| D27（正限位）| 5V | GND | **绿色** × 3 |
| Z轴 | D28（负限位）| D29（原点）| D30（正限位）| 5V | GND | **紫色** × 3 |

> 三个轴的 ④5V 和 ⑤GND 出线可以并联到 Arduino 的同一个 5V 和 GND 引脚。
> 也就是说 Arduino 端最终只需要占 1 个 5V 引脚和 1 个 GND 引脚。

> **怎么知道哪个传感器是负限位、哪个是原点、哪个是正限位？**
> 看你装传感器的位置！回忆第八阶段装光电开关时的布局：
> - 行程一端的传感器 = 负限位（X轴D22/Y轴D25/Z轴D28）
> - 紧挨着负限位内侧的 = 原点（X轴D23/Y轴D26/Z轴D29）
> - 行程另一端的 = 正限位（X轴D24/Y轴D27/Z轴D30）
>
> 如果搞混了也没关系，后面软件测试时可以调整。

### 20.5 具体操作步骤

以 X 轴为例，其他两轴同理：

```
  第一步：准备端子排
  ① 从10位端子排上掰下5位（沿接缝掰就行）
  ② 用记号笔或标签纸在端子排上标注：信号1 信号2 信号3 5V GND

  第二步：接传感器线到端子排
  ③ 把X轴3个传感器的白色线分别剥出铜线，插到端子排的 ①②③ 号位，拧紧螺丝
  ④ 把3根棕色线一起插到 ④ 号位（5V），拧紧
  ⑤ 把3根蓝色线一起插到 ⑤ 号位（GND），拧紧

  第三步：接杜邦线到端子排（出线到Arduino）
  ⑥ 取3根蓝色杜邦线，剪掉母头那端，剥出铜线
  ⑦ 铜线端分别插到端子排的 ①②③ 号位（和传感器白色线同一个端子位），拧紧
  ⑧ 取1根红色杜邦线，同样处理，铜线端插到 ④ 号位
  ⑨ 取1根黑色杜邦线，铜线端插到 ⑤ 号位
  ⑩ 杜邦线的公头分别插到 Arduino 的 D22、D23、D24、5V、GND
```

> Y轴：用**绿色**杜邦线，接 D25、D26、D27
> Z轴：用**紫色**杜邦线，接 D28、D29、D30
> 三个轴的红色（5V）和黑色（GND）杜邦线可以并排插到 Arduino 同一个引脚

### 20.6 自检清单

- [ ] 每个轴的端子排上有3根传感器白色信号线 + 对应颜色杜邦线 ✓
- [ ] 每个轴的端子排 ④号位：3根棕色线 + 1根红色杜邦线 ✓
- [ ] 每个轴的端子排 ⑤号位：3根蓝色线 + 1根黑色杜邦线 ✓
- [ ] X轴蓝色杜邦线 → D22、D23、D24 ✓
- [ ] Y轴绿色杜邦线 → D25、D26、D27 ✓
- [ ] Z轴紫色杜邦线 → D28、D29、D30 ✓
- [ ] 红色杜邦线（5V）→ Arduino 5V ✓
- [ ] 黑色杜邦线（GND）→ Arduino GND ✓
- [ ] 每个端子排螺丝都拧紧了，线拽不动 ✓
- [ ] 棕色线（5V）和蓝色线（GND）没有碰到一起 ✓

### 21.1 目视检查（逐条过）

**Z轴驱动器**：同上，但信号线是紫色杜邦线 D6（PLS-）、D7（DIR-）

### 21.2 检查有没有短路

**什么是短路**：正极线（红色/棕色）和负极线（黑色/蓝色）的裸铜线碰到了一起。短路会在通电瞬间产生很大的电流，烧坏设备。

检查方法：

1. **看**：所有接线端子附近有没有铜线露在外面碰到旁边的端子？
2. **看**：电源的 V+ 和 V- 之间的线有没有交叉碰到？

```cpp
  pinMode(X_PLS, OUTPUT);
  pinMode(X_DIR, OUTPUT);

  // 打开串口（用于在电脑上看信息）

  Serial.println("电机将来回移动");

  delay(2000);

void loop() {
  // === 正方向转动 ===
  Serial.println("正方向移动 3200步（一圈）...");
  digitalWrite(X_DIR, HIGH);  // 设方向为正

  for (int i = 0; i < 3200; i++) {
    digitalWrite(X_PLS, HIGH);
    delayMicroseconds(200);    // 脉冲高电平时间
    digitalWrite(X_PLS, LOW);
    delayMicroseconds(200);    // 脉冲低电平时间

  delay(1000);  // 停1秒

  for (int i = 0; i < 3200; i++) {
    digitalWrite(X_PLS, HIGH);
    delayMicroseconds(200);
    digitalWrite(X_PLS, LOW);
    delayMicroseconds(200);
  }

  Serial.println("暂停1秒...");
  delay(1000);  // 停1秒

  // 然后 loop() 会自动重复，电机继续来回转
}
```

## 二十五、第二十阶段：回零测试

> 回零（Homing）是龙门架最基本的操作：开机后让滑块自动找到"原点"位置。
> 做完这一步，你的龙门架就基本可以用了！

### 25.1 回零的原理

```
回零过程（以X轴为例）：

  1. 电机开始慢慢向负方向（靠近负限位的方向）转动
     ←───── 滑块在移动

  2. 当感应片穿过"原点传感器"时，传感器发出信号
     ←──[感应片]──U 原点传感器 → 触发了！

  3. Arduino 收到信号，命令电机立刻停下来
     滑块停在原点位置

  4. 这个位置就被定义为坐标 0
     以后所有的移动都以这里为基准
```

### 25.2 回零测试代码

新建文件，复制粘贴：

```cpp
// ============================================
// 智能旋涂仪 — X轴回零测试
// 功能：X轴自动找到原点位置
// ============================================

// X轴引脚
const int X_PLS = 2;
const int X_DIR = 3;
const int X_HOME = 23;     // X轴原点传感器
const int X_NEG_LIMIT = 22; // X轴负限位传感器

// DS-ES61 传感器：NPN亮通型
// 有遮挡（感应片插入）→ HIGH = 触发
// 无遮挡 → LOW = 未触发
const int SENSOR_TRIGGERED = HIGH;

// X轴硬件安装方向与逻辑方向相反，需要取反
// HIGH = 实际向负方向移动（朝原点/负限位）
// LOW  = 实际向正方向移动
const int X_DIR_NEGATIVE = HIGH;
const int X_DIR_POSITIVE = LOW;

void setup() {
  pinMode(X_PLS, OUTPUT);
  pinMode(X_DIR, OUTPUT);
  pinMode(X_HOME, INPUT_PULLUP);
  pinMode(X_NEG_LIMIT, INPUT_PULLUP);

  Serial.begin(9600);
  Serial.println("=== X轴回零测试 ===");
  Serial.println("X轴将自动寻找原点位置...");
  Serial.println("（如果方向反了，立刻拔USB线断电！）");
  delay(2000);

  // 执行回零
  homeX();
}

void homeX() {
  // 第一步：向负方向移动（朝原点传感器方向）
  Serial.println("向原点方向移动中...");
  digitalWrite(X_DIR, X_DIR_NEGATIVE);

  while (true) {
    // 检查是否触发了负限位（安全保护）
    if (digitalRead(X_NEG_LIMIT) == SENSOR_TRIGGERED) {
      Serial.println("触发负限位！反方向退回一点...");
      // 反方向退回500步
      digitalWrite(X_DIR, X_DIR_POSITIVE);
      for (int i = 0; i < 500; i++) {
        digitalWrite(X_PLS, HIGH);
        delayMicroseconds(300);
        digitalWrite(X_PLS, LOW);
        delayMicroseconds(300);
      }
      // 再换回负方向继续找原点
      digitalWrite(X_DIR, X_DIR_NEGATIVE);
    }

    // 检查是否到达原点
    if (digitalRead(X_HOME) == SENSOR_TRIGGERED) {
      Serial.println("找到原点！停止。");
      break;  // 跳出循环，停止
    }

    // 发一个脉冲，电机走一小步
    digitalWrite(X_PLS, HIGH);
    delayMicroseconds(300);
    digitalWrite(X_PLS, LOW);
    delayMicroseconds(300);
  }

  Serial.println("回零完成！当前位置为坐标零点。");
}

void loop() {
  // 回零完成后不再做任何事
  // 后面会加入更多功能
}
```

## 二十六、第二十一阶段：Z轴刹车接线

> **安全提醒**：所有接线都在**断电**状态下操作！先拔掉24V电源插头，再开始。

### 26.1 为什么Z轴需要刹车

Z轴是垂直的。如果断电了，电机没有保持力，Z轴上的东西（旋涂头等）会因为重力直接掉下来。

刹车的作用：**断电时刹车锁住，防止掉落；通电时刹车松开，正常运动。**

### 26.2 工作原理

电机里有一个"刹车装置"——它像一个弹簧夹子，**平时是夹紧的**（锁住），给它通24V电才会**松开**。

我们用 DSTUR-T80 USB继电器模块的 **第2路（CH2）** 来控制刹车的24V通断：

```
电脑发送 CH2 ON 指令
  ↓
继电器 CH2 闭合，24V 接通
  ↓
刹车通电松开 → 电机可以转动

电脑发送 CH2 OFF 指令（或 USB 断开 / 断电）
  ↓
继电器 CH2 断开，24V 断了
  ↓
刹车弹簧自动夹紧 → Z轴被锁住不会掉
```

> **安全特性**：继电器用的是 NO（常开）端，断电时自动断开 → 刹车自动锁住。即使电脑崩溃或 USB 线掉了，Z轴也不会掉下来。

### 26.3 你需要接哪些线

只需要 **3 根线**：

| 从哪里来 | 接到哪里 | 用什么线 |
|---------|---------|---------|
| 24V电源 +V | 继电器 CH2 的 **COM** 端子（中间） | 导线 |
| 继电器 CH2 的 **NO** 端子 | Z轴电机刹车**红色**线 | 导线 |
| Z轴电机刹车**黑色**线 | 24V电源 -V | 导线 |

> **驱动器的 BREAK+/BREAK- 不用接了**。刹车改由 USB 继电器直接控制，不经过驱动器。

### 26.4 找到继电器 CH2 的端子

在 DSTUR-T80 继电器板上找到第 2 路继电器（CH2），它有 3 个蓝色螺丝端子：

```
  DSTUR-T80 继电器板 CH2 端子：

  ┌──────┬──────┬──────┐
  │  NC  │  COM │  NO  │
  │ 常闭 │ 公共 │ 常开 │  ← 我们只用 COM 和 NO
  └──────┴──────┴──────┘
```

> **NC（常闭）不接**。我们接 COM 和 NO，这样继电器断电时电路断开（刹车锁住），安全。

### 26.5 开始接线（断电操作！）

> **⚠️ 确认 24V 电源插头已经拔掉！**

**第一步：接电源到继电器 COM 端**

从 24V 电源的 +V 端子引一根线，接到继电器 CH2 的 **COM** 端子，拧紧螺丝。

```
  24V电源 +V ──────→ 继电器 CH2 COM
```

**第二步：接继电器 NO 端到电机刹车红线**

找到 Z轴电机上之前用胶带包好的 **2根细线**（红色和黑色）。

1. 撕掉胶带，剥出铜线头（如果没剥的话用剥线钳剥 5mm）
2. 把电机**刹车红色线**接到继电器 CH2 的 **NO** 端子，拧紧

```
  继电器 CH2 NO ──────→ Z轴电机刹车红色线
```

**第三步：接电机刹车黑线到电源负极**

把电机**刹车黑色线**接到 24V 电源的 -V 端子，拧紧。

```
  Z轴电机刹车黑色线 ──────→ 24V电源 -V
```

> 如果刹车线太短够不到，用杜邦线做延长（剪一根杜邦线，铜线端和刹车线拧在一起，用电工胶带包好）。

**完整接线图**：

```
  24V电源 +V ──→ 继电器 CH2 COM
                  继电器 CH2 NO ──→ 电机刹车红线
  24V电源 -V ──→ 电机刹车黑线
```

### 26.6 接线自检清单

- [ ] 继电器 CH2 **COM** 端子：接了 24V 电源 +V
- [ ] 继电器 CH2 **NO** 端子：接了电机刹车**红色**线
- [ ] 继电器 CH2 **NC** 端子：**没有接线**（空着是对的）
- [ ] 电机刹车**黑色**线：接了 24V 电源 -V
- [ ] 所有螺丝都拧紧了，轻拽每根线都不会松
- [ ] 红色线（+）和黑色线（-）没有碰到一起
- [ ] DSTUR-T80 继电器板的 USB 线已插到电脑

### 26.7 通电测试刹车

> 确认所有线检查完毕后再通电。

**测试步骤：**

1. 插上 24V 电源插头，开电
2. 确认 DSTUR-T80 的 USB 线已插到 Mac
3. 在终端运行以下命令释放刹车（CH2 ON）：

```bash
python3 -c "
import serial, time
s = serial.Serial('/dev/cu.usbmodem6670E00119391', 9600, timeout=1)
time.sleep(0.3)
s.write(bytes([0xA0, 0x02, 0x01, 0xA3]))
print('CH2 ON（刹车释放）:', s.readline().decode().strip())
s.close()
"
```

4. 听 → 应该听到继电器"**咔**"一声 + 刹车"**咔**"一声松开
5. 用手轻推 Z轴滑块 → 推起来**很紧但能动**（电机在保持，刹车已松开）

如果以上都正常，继续测试锁定（CH2 OFF）：

```bash
python3 -c "
import serial, time
s = serial.Serial('/dev/cu.usbmodem6670E00119391', 9600, timeout=1)
time.sleep(0.3)
s.write(bytes([0xA0, 0x02, 0x00, 0xA2]))
print('CH2 OFF（刹车锁定）:', s.readline().decode().strip())
s.close()
"
```

6. 听 → 继电器"**咔**"一声 + 刹车锁住
7. 用手推 Z轴滑块 → **推不动**（刹车锁住了）

**恭喜！刹车工作正常！**

### 26.8 测试不通过怎么办

**情况1：继电器咔声正常但刹车没反应**
- 检查 COM 端接的是不是电源 +V（不是 -V）
- 检查 NO 端接的是不是电机刹车红线
- 检查刹车黑线是不是接到了电源 -V
- 万用表蜂鸣挡测每段线是否导通

**情况2：终端报错找不到端口**
- 运行 `ls /dev/cu.usb*` 确认端口名
- 继电器 USB 线可能松了，重新拔插

**情况3：断电后 Z轴滑块还能推动（刹车没锁住）**
- 检查电机刹车线红/黑是否接紧了
- 确认接的是 **NO** 端（不是 NC 端）——NC 是常闭，逻辑相反

**情况4：刹车一直锁着不松开**
- 确认继电器回复了 "CH2:ON"
- 检查 COM 端到电源 +V 是否导通
- 检查 NO 端到刹车红线是否导通

## 二十七、第二十二阶段：ALM 报警接线

> **定位**：这一章是 [Phase 0 硬件安全底座](phase0-硬件安全底座.md) 的核心硬件动作。做完之后驱动器报警时 Arduino 能立刻知道，为后续 grbl-Mega-5X 迁移（Phase 1）和硬件急停联锁（issue #006）打基础。
>
> **前置**：刹车接线（§26）已完成、所有驱动器能正常工作。
>
> **安全提醒**：所有接线都在**断电**状态下操作。先拔 24V 电源插头。

### 27.1 为什么要接 ALM

驱动器正常工作时绿灯常亮。一旦出现故障——**缺相**（电机线松了）、**过压/过流**（电源异常）、**超差**（闭环模式下位置跑偏）——驱动器会：

1. 红灯开始闪烁（闪烁次数对应故障码，见手册 §七）
2. 电机停止转动（但**不抱闸**，可能被重力拖动）
3. ALM 端口输出"报警信号"

如果 Arduino 不读 ALM，它完全不知道驱动器已经罢工——还在疯狂发脉冲，上位机也还在以为电机正常移动，结果就是**撞机 / 丢片 / 样品报废**。接上 ALM 后，固件/grbl 一旦读到报警信号就立刻停下来报错。

本项目的自研固件（`firmware/motor_control/motor_control.ino`）早就预留了读 ALM 的逻辑：

- `ALM_PINS[] = {31, 32, 33}` → X/Y/Z 三轴各占一路
- `pinMode(ALM_PINS[i], INPUT_PULLUP)` → Arduino 内部 5V 上拉
- `alarmTriggered(pin)` → `digitalRead(pin) == LOW` 就视为报警
- 归零流程里也有 ALM 检查（读到 LOW 立刻中止归零）

只差物理接线这一步。

### 27.2 驱动器 ALM 端口是什么

翻到驱动器正面，找到最顶端那个 **2 针端子**：

```
  2HSS57-C 驱动器正面（从上到下）：

  ┌─────────────────────────────────────────────┐
  │  ① 报警信号输出端口（2 个端子）             │
  │  ┌─────┬─────┐                              │
  │  │ALM+ │ALM- │   ← 我们这次要接这里         │
  │  │  1  │  2  │                              │
  │  └─────┴─────┘                              │
  │                                             │
  │  ② 刹车/到位端口（4 个端子）                │
  │  BREAK+ BREAK- PEND+ PEND-                  │
  │  （BREAK 已在 §26 用 USB 继电器取代了）     │
  │                                             │
  │  ③ 控制信号端口（6 个端子）                 │
  │  PLS+ PLS- DIR+ DIR- ENA+ ENA-              │
  │  （已接 Arduino D2~D7）                     │
  │                                             │
  │  ④ 编码器端口（6 个端子）                   │
  │  PB+ PB- PA+ PA- VCC GND                    │
  │  （DB9 已接通，闭环模式）                   │
  │                                             │
  │  ⑤ 功率端口（6 个端子）                     │
  │  A+ A- B+ B- VCC GND                        │
  │  （电机线 + 24V 电源已接）                  │
  └─────────────────────────────────────────────┘
```

手册（`hardware/龙门架/驱动器/2HSS57-C (V2.01-T) (1).pdf` §3.1）明确写明 ALM 是 **光耦隔离的集电极开路输出**：

```
  驱动器内部：
                   ┌── ALM+ （= 光耦三极管集电极，引出到外部）
   故障 ──▶ LED ──┤
                   └── ALM- （= 光耦三极管发射极，引出到外部）

  正常时：光耦断开 → ALM+ 和 ALM- 之间"开路"
  报警时：光耦导通 → ALM+ 和 ALM- 之间"短路"
```

这意味着 ALM 就像一个**开关**：平时断开，报警时闭合。

### 27.3 Arduino 这一侧怎么读

Arduino 的 `INPUT_PULLUP` 模式会把引脚通过内部 30kΩ 电阻接到 5V。于是：

```
  Arduino D31 ←── 内部 5V 上拉（通过 30kΩ）
       │
       │←────── 接 ALM+
       │
       ▼
  驱动器内部光耦三极管（正常时断开）
       │
       ▼
       ALM-
       │
       │←────── 接 Arduino GND
       ▼
      GND

  正常：光耦断开 → D31 被内部上拉到 5V → digitalRead = HIGH → 没报警
  报警：光耦导通 → D31 被拉到 GND → digitalRead = LOW → alarmTriggered = true
```

**不需要外接电阻**——Arduino 内部上拉 5V/30kΩ 只产生 ~0.17mA 电流，远远在光耦三极管的耐受范围内。

### 27.4 引脚分配（最重要的一张表）

| 轴 | 驱动器 ALM+ 接到 | 驱动器 ALM- 接到 |
|---|---|---|
| **X 轴** | Arduino **D31** | Arduino **GND** |
| **Y 轴** | Arduino **D32** | Arduino **GND** |
| **Z 轴** | Arduino **D33** | Arduino **GND** |

> 三个轴的 ALM- 可以**共用一根**回到 Arduino GND 的线（省 2 根杜邦线）。Arduino Mega 有 5 个 GND 引脚，随便用哪个都行。

### 27.5 D31/D32/D33 在 Arduino Mega 上的物理位置

Arduino Mega 的 D22-D53 在板子**一侧的双排插针**上（和 D0-D13 在对面）。双排布局：

```
   板子边缘（靠外）：
   ┌────────────────────────────────────────────┐
   │  D22  D24  D26  D28  D30  D32  D34  ...    │  ← 上排（偶数）
   │   ○    ○    ○    ○    ○    ○    ○          │
   │                                             │
   │  D23  D25  D27  D29  D31  D33  D35  ...    │  ← 下排（奇数）
   │   ○    ○    ○    ○    ○    ○    ○          │
   └────────────────────────────────────────────┘
              （D22-D30 已经接了传感器）

  这次要接：
    D31 ← X轴 ALM+
    D32 ← Y轴 ALM+
    D33 ← Z轴 ALM+
```

紧挨着现有传感器线——数过去即可。

### 27.6 接线步骤（断电操作！）

> **⚠️ 再次确认：24V 电源插头已拔掉。**

**准备材料**：
- 6 根杜邦线（母对母，最好 20~30cm 长；或母头杜邦 + 一小段导线）
- 如果驱动器 ALM 端子需要细线才能插进去，用剥线钳剥 5mm 铜头

**第一步：接 X 轴驱动器的 ALM**

1. 在 X 轴驱动器正面找到最顶端的 2 针端子（ALM+/ALM-）
2. 拿一根杜邦线，一端拧进 **ALM+** 端子拧紧，另一端插 Arduino **D31**
3. 拿另一根杜邦线，一端拧进 **ALM-** 端子拧紧，另一端插 Arduino 的任意一个 **GND**

```
  X 驱动器 ALM+ ──杜邦线──→ Arduino D31
  X 驱动器 ALM- ──杜邦线──→ Arduino GND
```

**第二步：接 Y 轴驱动器的 ALM**

1. Y 轴驱动器的 ALM+ → Arduino **D32**
2. Y 轴驱动器的 ALM- → Arduino **GND**（可以和 X 轴共用 GND，或另找一个）

**第三步：接 Z 轴驱动器的 ALM**

1. Z 轴驱动器的 ALM+ → Arduino **D33**
2. Z 轴驱动器的 ALM- → Arduino **GND**

**完整接线图**：

```
                  ┌────────────┐
                  │  Arduino   │
                  │  Mega 2560 │
                  │            │
                  │  D31 ←────────── X 驱动器 ALM+
                  │  D32 ←────────── Y 驱动器 ALM+
                  │  D33 ←────────── Z 驱动器 ALM+
                  │  GND ←────────── X 驱动器 ALM-
                  │       ←────────── Y 驱动器 ALM-
                  │       ←────────── Z 驱动器 ALM-
                  └────────────┘
```

### 27.7 接线自检清单

- [ ] X 驱动器 ALM+ → Arduino D31，线拧紧
- [ ] X 驱动器 ALM- → Arduino GND，线拧紧
- [ ] Y 驱动器 ALM+ → Arduino D32，线拧紧
- [ ] Y 驱动器 ALM- → Arduino GND，线拧紧
- [ ] Z 驱动器 ALM+ → Arduino D33，线拧紧
- [ ] Z 驱动器 ALM- → Arduino GND，线拧紧
- [ ] 所有 ALM+ 线**没有**接成 5V（会直接短路 Arduino！这是常见错误）
- [ ] D31 和 D33 接在**下排**、D32 接在**上排**，没有错位
- [ ] 没有碰到旁边 D22-D30 的传感器线
- [ ] 24V 电源插头仍是**拔掉**状态

### 27.8 通电测试 ALM

> **前提**：全部自检通过。先测试"无报警"状态，再手动触发报警。

**第一步：烧录验证 sketch**

上传 `firmware/alm_test/alm_test.ino`（Phase 0 专用的极简测试程序，只读 D31/D32/D33 并串口输出）。

> **上传前务必关闭所有占用串口的程序**：cncjs、网页控制面板、Python 脚本。否则上传失败要重启电脑才能恢复串口（见 MEMORY.md 注意事项）。

**第二步：打开串口监视器**

Arduino IDE → 工具 → 串口监视器，波特率 **115200**。应该每 500ms 看到一行：

```
ALM  X=OK  Y=OK  Z=OK
ALM  X=OK  Y=OK  Z=OK
...
```

如果看到任何一个是 `ALARM` 而驱动器绿灯正常亮——**说明接线错了**（最常见：ALM+ 和 ALM- 接反，或 ALM- 没接 GND）。

**第三步：通电（接通 24V）**

```
ALM  X=OK  Y=OK  Z=OK
```

驱动器绿灯亮、所有轴都显示 OK。

**第四步：手动触发 X 轴报警验证**

这是验证"Arduino 能读到报警"的关键测试。**任选一种方法**：

**方法 A（推荐，零风险）——软件模拟**：拔掉 D31 那根杜邦线（从 Arduino 侧拔），用另一根杜邦线把 D31 和 GND 短接 1 秒：

```
手动短接 D31 ↔ GND → 串口应立刻输出：
ALM  X=ALARM  Y=OK  Z=OK
```

松开后恢复 `X=OK`。验证后把原来的 ALM+ 线插回 D31。

**方法 B（真实故障）——制造缺相**：断电 → 拔掉 X 轴的一根电机相线（比如红 A+）→ 重新通电：

1. X 驱动器红灯开始闪 6 次（缺相故障码）
2. 串口输出 `ALM  X=ALARM  Y=OK  Z=OK`
3. 断电、把相线插回去、通电 → 绿灯恢复 → `X=OK`

**第五步：对 Y、Z 轴重复方法 A**

确认所有三轴的 ALM 都能被 Arduino 正确读到。

### 27.9 测试不通过怎么办

**情况 1：上电后串口一直显示 `X=ALARM Y=ALARM Z=ALARM`（驱动器绿灯正常）**

- ALM+ 和 ALM- 接反了 → 把每个驱动器的两根线对调
- 或 ALM- 根本没接到 GND → 光耦三极管的发射极悬空，导致误触发

**情况 2：手动触发方法 A 也读不到 ALARM**

- D31/D32/D33 的杜邦线根本没插稳 → 拔出来重插
- 固件 sketch 没上传成功 → 重新上传 `alm_test.ino`，关注 IDE 下方编译输出
- 串口选错 → 确认是 Arduino Mega 的 `/dev/cu.usbmodem*` 不是 DSTUR-T80 继电器的端口

**情况 3：驱动器真的报警了但串口没反应**

- ALM+ 那根线断了 / 接触不良 → 万用表蜂鸣挡测从驱动器 ALM+ 端子到 Arduino D31 是否导通
- 驱动器 ALM 端口故障（罕见）→ 换另一个驱动器的 ALM 端子交叉验证

**情况 4：Arduino 进入"死机"不输出任何东西**

- 可能 ALM+ 线不小心碰到了 5V（短路）→ 断电、检查每根线走向
- USB 线松了 → 重插 Arduino USB 线

ALM 物理接线完成后，继续往下走 [Phase 0 runbook §3 Z 刹车软件策略](phase0-硬件安全底座.md)——把软件层面的刹车联动策略写进 orchestrator 设计。硬件这一侧就暂停在这里，等 Phase 1 的 grbl-Mega-5X spike 启动。

## 二十八、电控常见问题

### Q：驱动器通电后红灯闪6次（电机缺相）

最常见的原因：电机相线（红蓝绿黑4根粗线）中有一根没接紧，或者接错了端子。

解决：断电，检查功率端口的4根线是否牢固，线色是否对应（红A+蓝A-绿B+黑B-）。

### Q：电机嗡嗡响但不转

可能原因：
1. 联轴器打滑 → 拧紧联轴器的紧定螺钉
2. 脉冲太快电机跟不上 → 把代码里的 `delayMicroseconds(200)` 改大一点，比如 `500`

### Q：代码上传失败

1. 确认 Arduino IDE 里选对了板子（Arduino Mega or Mega 2560）
2. 确认选对了端口
3. 拔掉 Arduino USB 线重新插
4. 重新选择端口
5. 再试一次上传

### Q：电机转动时龙门架抖动或有异响

1. 检查机械结构螺丝有没有松
2. 可能细分设置太低 → 我们已经设了3200，应该够平滑了
3. 可以尝试把 SW7 拨到 ON（开启脉冲平滑），看看是否改善

### Q：传感器一直显示"触发"或一直"未触发"

1. 检查棕色线（5V）和蓝色线（GND）有没有接反
2. 检查传感器有没有通电（传感器上通常有一个小LED灯，通电时会亮）
3. 检查传感器的U形缺口方向是否朝着感应片

### Q：Arduino 5V引脚不够用怎么办

Arduino Mega 有2个 5V 和3个 GND 引脚。如果不够用，可以：
1. 把多根线拧在一起接到同一个引脚
2. 或者用一个小面包板来分流

### Q：Z轴断电后滑块掉下来了

说明刹车没有正常工作。检查：
1. 继电器接线是否正确
2. 刹车线（红/黑2根）是否接紧了
3. 继电器的线圈电压是不是 24VDC（不能用 220VAC 的！）

### Q：我接错线烧了驱动器怎么办

驱动器有过流和过压保护，一般不会轻易烧。但如果真的烧了：
1. 不要慌，驱动器可以单独再买一个（淘宝搜"杰美康 2HSS57-C"）
2. 找到接错的线路，修正后再换上新驱动器
