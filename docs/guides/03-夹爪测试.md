# 智能旋涂仪 — 电动夹爪测试教程（零基础版）

> 夹爪到了！在把它集成到龙门架之前，我们先单独测试它，确认它能正常工作。
>
> **你手上的夹爪型号**：
> - 控制器：混合伺服力控电夹爪 Y1（20-27VDC）
> - 电机本体：SAMSR ETQ42-20DL-18-2SS-N（42mm 步进电机 + 平行夹爪）
>
> **控制方式**：夹爪的基本开/合通过 **24V通断** 控制——给控制器的24V控制引脚接通24V就夹合，断开就松开。我们用 DSTUR-T80 USB继电器模块来切换这个24V信号。
>
> **RS485 用途**：夹爪控制器上的 G/T/R 接口是 RS485 Modbus RTU（115200, 8N1），用于调节夹持力、速度、位置等高级参数。基本开合测试不需要用到。
>
> **安全提醒**：测试过程中不要把手指伸进夹爪的两个夹指之间，夹爪夹合时力度不小，会夹伤手指。
>
> **操作原则**：所有接线操作都在**断电**状态下进行。接完线、检查完毕，最后一步才通电。

## 一、认识夹爪系统（动手前必读）

### 1.1 夹爪系统组成

你手上有这些东西：

| 部件 | 长什么样 | 作用 |
|------|---------|------|
| 控制器（黑色方盒子） | 铝壳方盒，标签写"混合伺服力控电夹爪 Y1"，底部有一排彩色线 | 大脑——接收指令、驱动电机 |
| 电机+夹爪（银色金属件） | 42mm步进电机上面装了一个平行开合的夹爪机构 | 手指——执行夹取/放开动作 |
| DSTUR-T80 USB继电器 | 蓝色PCB板，8个蓝色继电器方块，一个USB口 | 开关——用来接通/断开夹爪的24V控制信号 |

控制器和电机之间已经用线连好了（出厂就接好的），你不需要拆开它们之间的连线。

### 1.2 控制器接口说明

看控制器标签（正面），从上到下有这些接口：

```
┌────────────────────────┐
│  混合伺服力控电夹爪 Y1  │
│                        │
│  NPN ○  PNP ○  ← 拨码开关（选NPN或PNP模式）
│                        │
│  OUT:                  │
│    V-  ← 电机输出（绿色端子，已接好，不用管）
│    V+  ← 电机输出（绿色端子，已接好，不用管）
│                        │
│  5V   ← 5V逻辑电源（可选，暂不用）
│  COM- ← 电源负极（GND）
│  24V  ← 24V控制引脚（接通24V=夹合，断开=松开）
│                        │
│  G    ← RS485 GND（高级调参用，暂不接）
│  T    ← RS485-A（高级调参用，暂不接）
│  R    ← RS485-B（高级调参用，暂不接）
└────────────────────────┘
```

**你需要接的线**：

| 接口 | 接到哪里 | 说明 |
|------|---------|------|
| V+/V-（绿色端子） | 24V电源 +V/-V | 电机供电，**常接**，不经过继电器 |
| COM- | 24V电源 -V | 控制器电源负极 |
| 24V | 继电器CH1的NO端 | 通过继电器控制——接通=夹合，断开=松开 |
| G / T / R | 暂不接 | 以后需要调力/速度时接 USB转RS485 适配器 |

### 1.3 测试架构

```
Mac 电脑
  │
  ├── USB ──→ DSTUR-T80 USB继电器（9600 baud）
  │              ├── CH1 ──→ 夹爪24V控制引脚（ON=夹合，OFF=松开）
  │              └── CH2~CH8 备用
  │
  └── （以后）USB转RS485 ──→ 夹爪 G/T/R（调力/速度/位置）

24V 电源
  ├── +V ──→ 夹爪绿色端子 V+（电机，常接）
  ├── +V ──→ 继电器CH1 COM端
  ├── -V ──→ 夹爪绿色端子 V-（电机，常接）
  └── -V ──→ 夹爪 COM-
```

> **为什么用 USB 继电器而不是 Arduino？**
> 夹爪的基本控制就是"24V通/断"，用 DSTUR-T80 USB继电器最简单——USB插电脑，发一条串口指令就能开关。Arduino 已经在忙着管电机脉冲和传感器，不给它加活。而且继电器模块自带光耦隔离，24V负载不会影响其他设备。

### 1.4 DSTUR-T80 USB继电器简介

| 参数 | 值 |
|------|-----|
| 型号 | DIUSTOU DSTUR-T80 |
| 通道数 | 8路（我们用CH1控制夹爪，CH2控制Z轴刹车） |
| 继电器 | SRD-05VDC-SL-C（5V线圈，触点10A/30VDC） |
| 隔离 | 光耦隔离 |
| 通信 | USB串口，9600 baud |
| 供电 | USB供电（5~32V） |
| Mac端口 | `/dev/cu.usbmodem6670E00119391` |

**控制协议**：

```
发送：0xA0 [通道] [开关] [校验和]
  通道：0x01=CH1, 0x02=CH2, ..., 0x08=CH8
  开关：0x01=ON, 0x00=OFF
  校验和 = 0xA0 + 通道 + 开关（取低8位）

响应：文本，如 "CH1:ON"、"CH1:OFF"
```

**例子**：
- 夹爪夹合（CH1 ON）：`0xA0 0x01 0x01 0xA2`
- 夹爪松开（CH1 OFF）：`0xA0 0x01 0x00 0xA1`

## 三、测试一：上电测试（仅接电机电源）

> **目标**：确认控制器和电机能正常上电，观察是否有初始化动作。
> 这一步不需要继电器，只接电机电源就行。

### 步骤

**⚠️ 确保24V电源220V输入线已拔掉（完全断电状态）**

#### 第①步：接电机电源（绿色端子）

找到控制器上的绿色端子（标注 V+/V-），这是给电机供电的。

**接法**：
```
控制器 V+（绿色端子）──→ 24V电源 +V 端子
控制器 V-（绿色端子）──→ 24V电源 -V 端子
```

#### 第②步：接控制器电源负极

```
控制器 COM- ──→ 24V电源 -V 端子
```

> **注意**：这一步先**不接**控制器的 `24V` 引脚。那个引脚是控制夹合的，后面通过继电器来控制。

#### 第③步：用万用表验证（推荐）

在通电前用万用表的**蜂鸣/导通挡**检查：

1. 把万用表拨到蜂鸣挡（二极管/蜂鸣挡）
2. 一支表笔触碰控制器 V+ 绿色端子出来的线头，另一支触碰电源 +V 端子
3. 如果"嘀"一声响 → 说明这根线接对了
4. 同样检查 V- 和 COM- 是否都接到电源 -V
5. **交叉检查**：V+ 的线碰 -V 端子，应该**不响**。如果响了 → 接反了，重新检查！

#### 第④步：通电

1. 确认接线无误
2. 插上24V电源的220V输入线
3. 打开电源开关

#### 第⑤步：观察现象

上电后注意观察：

| 观察项 | 正常现象 | 异常现象 |
|--------|---------|---------|
| 控制器 | 可能有指示灯亮 | 冒烟、发烫、焦味 → **立即断电** |
| 电机 | 可能有轻微"咔"声或嗡嗡声（电机锁定） | 剧烈抖动 → 断电检查 |
| 夹爪 | 应该不动（因为24V控制引脚没接） | 自动开合 → 说明线接错了，断电检查 |

**在第七节的测试记录表中记录你观察到的现象。**

#### 第⑥步：断电

观察完毕后，**关闭电源开关**，为下一步接线做准备。

## 四、测试二：USB继电器连接与开合控制

> **目标**：通过 USB 继电器控制夹爪的24V控制引脚，实现夹合/松开。

### 4.1 继电器接线

**⚠️ 断电状态下接线！**

在 DSTUR-T80 继电器板上找到 CH1（第1路继电器）的接线端子。每路有3个端子：**COM**（公共端）、**NO**（常开）、**NC**（常闭）。

**我们用 NO（常开）端**——继电器断电时电路断开（夹爪松开），继电器通电时电路接通（夹爪夹合）。

**接法**：

```
24V电源 +V       ──→ 继电器 CH1 COM 端
继电器 CH1 NO 端 ──→ 夹爪控制器 24V 引脚
（夹爪 COM- 在上一步已经接到 24V电源 -V）
```

> **原理**：CH1 打开时，COM-NO 导通，24V 接到夹爪控制引脚，夹爪夹合。
> CH1 关闭时，COM-NO 断开，夹爪控制引脚无电压，夹爪松开。

### 4.2 连接USB继电器到电脑

用 USB 线把 DSTUR-T80 插到 Mac。

在终端运行：

```bash
ls /dev/cu.usb*
```

应该能看到继电器的端口：

```
/dev/cu.usbmodem6670E00119391    ← DSTUR-T80 USB继电器
```

> 如果同时插着 Arduino，会看到多个端口。继电器的端口名通常含 `usbmodem`，Arduino 的是 `usbserial`。分不清就拔掉继电器看哪个消失。

### 4.3 安装 Python 依赖

打开终端，运行：

```bash
pip3 install pyserial
```

> 如果提示权限问题，改用：`pip3 install --user pyserial`

### 4.4 通电并测试

1. 打开24V电源
2. 确认继电器USB已插上

在终端用 Python 直接测试（不需要专门的脚本）：

```bash
python3 -c "
import serial, time

# 打开继电器串口
port = '/dev/cu.usbmodem6670E00119391'
ser = serial.Serial(port, 9600, timeout=1)
time.sleep(0.5)

# 夹爪夹合（CH1 ON）
ser.write(bytes([0xA0, 0x01, 0x01, 0xA2]))
resp = ser.readline()
print('夹合:', resp)

time.sleep(3)  # 等3秒观察

# 夹爪松开（CH1 OFF）
ser.write(bytes([0xA0, 0x01, 0x00, 0xA1]))
resp = ser.readline()
print('松开:', resp)

ser.close()
print('测试完成')
"
```

#### 预期现象

| 时间 | 现象 |
|------|------|
| 发送夹合指令后 | 听到继电器"咔"一声，夹爪夹合，终端显示类似 `夹合: b'CH1:ON\r\n'` |
| 等待3秒 | 夹爪保持夹合状态 |
| 发送松开指令后 | 继电器"咔"一声，夹爪松开，终端显示类似 `松开: b'CH1:OFF\r\n'` |

### 4.5 反复测试

确认能正常开合后，多试几次：

```bash
python3 -c "
import serial, time

port = '/dev/cu.usbmodem6670E00119391'
ser = serial.Serial(port, 9600, timeout=1)
time.sleep(0.5)

for i in range(5):
    print(f'第 {i+1} 次：夹合...')
    ser.write(bytes([0xA0, 0x01, 0x01, 0xA2]))
    print(ser.readline())
    time.sleep(1)

    print(f'第 {i+1} 次：松开...')
    ser.write(bytes([0xA0, 0x01, 0x00, 0xA1]))
    print(ser.readline())
    time.sleep(1)

ser.close()
print('5次开合测试完成')
"
```

### 4.6 观察和记录

| 测试项 | 观察内容 | 你的记录 |
|--------|---------|---------|
| 夹合响应时间 | 从发指令到夹爪完全合拢大约几秒？ | |
| 松开响应时间 | 从发指令到夹爪完全张开大约几秒？ | |
| 最大开合距离 | 两个夹指之间最大距离（用尺子量，单位mm） | |
| 运动噪音 | 安静 / 轻微嗡嗡 / 很吵 | |
| 重复性 | 连续开合5次，每次位置是否一致？ | |

## 六、故障排查

### 6.1 上电后完全没反应

| 检查项 | 怎么查 |
|--------|--------|
| 电源开了吗？ | 确认电源指示灯亮 |
| 绿色端子V+/V-接对了吗？ | 万用表量控制器绿色端子V+和电源+V之间是否导通 |
| COM-接了吗？ | 万用表量控制器COM-和电源-V之间是否导通 |
| 正负极接反了吗？ | 万用表确认 +V 对应 V+，-V 对应 V-/COM- |
| 线头接触良好吗？ | 拧紧端子螺丝，确保铜线被夹住 |

### 6.2 上电后电机嗡嗡响但夹爪不动

- 这是正常的——步进电机通电后会锁定位置，发出轻微嗡嗡声
- 夹爪动作需要24V控制引脚通电（通过继电器控制）

### 6.3 Mac 找不到 USB 继电器端口

| 检查项 | 怎么查 |
|--------|--------|
| USB线接好了吗？ | 重新拔插USB线 |
| 换个USB口试试 | 有些USB口可能接触不好 |
| 端口被占？ | 终端运行 `lsof /dev/cu.usb*` 看有没有其他程序占着 |
| 继电器板有电吗？ | 板上应该有电源指示灯 |

### 6.4 发送指令后继电器没反应

| 检查项 | 怎么查 |
|--------|--------|
| 端口名对吗？ | `ls /dev/cu.usb*` 确认端口名 |
| 波特率对吗？ | 必须是 9600 |
| 指令格式对吗？ | 校验和 = 0xA0 + 通道 + 开关（取低8位） |
| 能听到继电器"咔"声吗？ | 如果听到咔声但夹爪不动 → 继电器正常，检查继电器到夹爪的接线 |

### 6.5 继电器咔声正常但夹爪不动

| 检查项 | 怎么查 |
|--------|--------|
| 继电器接的是NO端吗？ | 不要接NC端（NC是常闭，逻辑相反） |
| 24V电源+V接到COM端了吗？ | 万用表量COM端和电源+V之间是否导通 |
| NO端接到夹爪24V引脚了吗？ | 万用表量继电器ON时NO端是否有24V输出 |
| 夹爪COM-接到电源-V了吗？ | 必须形成回路，否则没电流 |

### 6.6 夹爪一直夹合不松开

- 检查是否接了NC端而非NO端（NC=常闭，继电器不通电时就导通）
- 检查24V控制引脚是否被直接短接到了24V电源（绕过了继电器）

## 附：后续集成到龙门架

测试全部通过后，下一步是把夹爪安装到 Z 轴末端。系统架构：

```
树莓派（上位机）
  ├── USB串口① → Arduino → XYZ 电机 + 传感器
  ├── USB串口② → DSTUR-T80 USB继电器
  │                 ├── CH1 → 夹爪（24V通断控制）
  │                 ├── CH2 → Z轴刹车（24V通断控制）
  │                 └── CH3~CH8 → 备用
  └── USB转RS485 → RS485 总线
                     ├── 旋涂模块
                     ├── 移液模块
                     └── 夹爪力/速度/位置调节（可选）
```

夹爪的基本开合由 USB 继电器控制。如果将来需要精细调节夹持力、速度、位置，可以通过 USB转RS485 适配器接夹爪的 G/T/R 引脚，走 Modbus RTU 协议（115200, 8N1）。
