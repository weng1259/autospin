# Phase 3.3 现场恢复：`ALARM:9` 归零失败

- **日期**：2026-04-24
- **场景**：Agent smoke 后，多次 `gantry_home` / `$H` 归零失败，表现为 `ALARM:9`、`HOMING_TIMEOUT` 或串口写入失败
- **结论**：本次直接可复现的 `$H -> ALARM:9` 由 homing seek 速度过高触发；降回 `$24=25` / `$25=500` 后归零成功
- **关联**：`docs/guides/04-grbl-固件配置.md §6.6`、`docs/issues/025-z-brake-emi-usb-reset.md`

## 现场证据

1. 只读诊断确认关键参数当时大多正确：
   - `$1=255`
   - `$3=6`
   - `$5=1`
   - `$21=1`
   - `$22=1`
   - `$23=0`
   - `$27=5.000`
   - `$130/$131/$132=280/280/95`
2. 当时 `$24=50.000`、`$25=1500.000`。
3. 只读 `?` 轮询 + 人工遮挡传感器验证：
   - Z+ 遮挡：出现 `Pn:Z`
   - X+ 遮挡：出现 `Pn:X`
   - Y+ 遮挡：出现 `Pn:Y`
   - 说明 grbl 能读到限位输入，传感器链路不是完全断开。
4. 标准 home 脚本在 `$25=1500` 下复现：
   - 命令：`tools/spikes/.venv/bin/python tools/grbl_stability_test.py home`
   - 日志：`tools/_stability_logs/20260424_200453_home.log`
   - 结果：`ALARM:9`，约 8.2s 失败。
5. 降速后重试：
   - 写入：`$24=25.000`、`$25=500.000`
   - 先 X/Y 负向各退 20mm
   - 命令：`tools/spikes/.venv/bin/python tools/grbl_stability_test.py home`
   - 日志：`tools/_stability_logs/20260424_201420_home.log`
   - 结果：归零成功，最终 `<Idle|MPos:-4.999,-4.999,-4.999|FS:0,0>`
