# 决策记录 — 传感器直连Arduino 5V，不加光耦隔离

**日期**：2026-03-09
**状态**：已采纳
**决策人**：FENG

## 背景

初期评估时曾认为传感器是24V的，需要光耦隔离才能接5V的Arduino。收到实物后确认参数。

## 决策

DS-ES61传感器直接使用Arduino 5V供电，信号线直接接数字引脚，不加光耦隔离。

## 考虑的替代方案

加3-4路光耦隔离模块（约20元），防止高压信号损坏Arduino。

## 理由

DS-ES61铭牌明确标注"5 to 24V DC"，支持5V供电和5V信号输出，直连完全安全。

## 影响

采购清单删除光耦隔离模块，节省约20元，接线也更简单。
