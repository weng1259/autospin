# 决策记录 — 电机控制方式选脉冲/方向（Pulse/Direction）

**日期**：2026-03-17
**状态**：已采纳
**决策人**：FENG

## 背景

杰美康 2HSS57-C 驱动器支持脉冲/方向和RS232两种控制方式。曾考虑是否能用RS485协议控制龙门架电机。

## 决策

采用脉冲/方向（GPIO）接口控制电机，Arduino发脉冲信号给驱动器。

## 考虑的替代方案

- RS232协议通过驱动器micro USB口控制（手册5.4节）
- RS485总线控制（驱动器不支持）

## 理由

脉冲/方向是运动控制行业标准（CNC、3D打印机均使用），实时性极高（微秒级），精度好（每个脉冲=一步），多轴协调容易（同时发脉冲即同步），而RS232有协议延迟、难以同步多轴。

## 影响

Arduino需要6个GPIO引脚（每轴2个：PLS+DIR），固件核心是脉冲发生逻辑。
