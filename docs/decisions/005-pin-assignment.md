# 决策记录 — Arduino GPIO引脚分配方案

**日期**：2026-03-17
**状态**：已采纳
**决策人**：FENG

## 背景

Arduino Mega有54个GPIO，需要为三轴电机和9个传感器分配引脚。

## 决策

- D2/D3 = X轴 PLS/DIR
- D4/D5 = Y轴 PLS/DIR
- D6/D7 = Z轴 PLS/DIR
- D22-D24 = X轴传感器（负限位/原点/正限位）
- D25-D27 = Y轴传感器
- D28-D30 = Z轴传感器
- X轴和Z轴方向在固件中取反

## 考虑的替代方案

无特别替代方案，D2-D7连续编号是自然选择。

## 理由

D2-D7连续编号便于记忆和代码编写，D22-D30也是连续的大排针适合接多个传感器，D0/D1保留给串口通信，模拟引脚保留备用。方向取反在固件中修正比重新接线简单。

## 影响

固件中X/Z轴的HIGH/LOW方向逻辑需要对调。
