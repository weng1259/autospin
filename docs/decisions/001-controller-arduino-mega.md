# 决策记录 — 控制器选择 Arduino Mega 2560

**日期**：2026-03-05
**状态**：已采纳
**决策人**：FENG

## 背景

需要一个控制器驱动三轴步进电机，读取9个限位传感器，并与上位机通信。

## 决策

使用 Arduino Mega 2560（CH340国产版）作为运动控制下位机。

## 考虑的替代方案

- ESP32：双核带WiFi/蓝牙，但5V兼容性麻烦
- 树莓派：Linux系统不是实时的，不适合微秒级脉冲控制
- 工控PLC：学习成本高，对本项目来说过于复杂

## 理由

54个GPIO引脚够用（6个电机+9个传感器+串口），4个硬件串口，5V直接驱动传感器无需电平转换，社区资料丰富，入门简单。

## 影响

需要安装CH340驱动（国产版），开发用arduino-cli命令行工具。
