# 决策记录 — 开环模式先行，闭环后补

**日期**：2026-03-17
**状态**：已采纳
**决策人**：FENG

## 背景

电机编码器是DB9插头，无法直接接驱动器散线端子，需要买DB9免焊接头转接。等待采购期间仍想先测试电机。

## 决策

初期用开环模式（驱动器SW8=ON），不接编码器，验证通电和控制逻辑后再切换闭环。

## 考虑的替代方案

等DB9免焊接头到货后直接上闭环调试。

## 理由

驱动器手册第16页明确 SW8=ON 时无需编码器可运行。开环先跑通整条链路，降低调试复杂度，排查问题时变量更少。

## 影响

当前三轴均为开环运行；后续DB9到货后只需拨SW8=OFF即可切闭环。开环模式下没有丢步检测。
