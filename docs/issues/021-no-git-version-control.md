# Issue #021 — 项目未纳入 Git 版本管理

**日期**：2026-03-24
**提出人**：Codex（审查 #026）
**状态**：resolved（2026-04-13 git init + tag `v0.1-pre-grbl-migration`）
**优先级**：中
**类型**：工程
**涉及文件**：项目根目录

## 问题描述

项目不是 Git 仓库，固件、网页和文档每次改动缺少 diff、回滚和发布标记。运动控制项目最怕"改了几处不知道哪一处把机器变坏了"。多人协作时问题更大。

## 建议方案

1. `git init` + 补 `.gitignore`（排除 `__pycache__`、`.DS_Store`、`报销/`）
2. 当前状态打 `v0.1` 基线 tag
3. 重要接线或拨码变化写进 commit message

## 验收标准

- [ ] 项目有 `.git` 目录
- [ ] 有 `.gitignore` 文件
- [ ] 当前状态有 tag 标记
