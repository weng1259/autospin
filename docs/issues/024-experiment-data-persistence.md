**日期**：2026-03-24

**状态**：open
**优先级**：低
**类型**：工程

## 问题描述

当前日志都是页面临时 DOM 文本或 Python 控制台输出，关闭即失。系统没有按"实验运行"维度持久保存参数、报警、操作动作。

## 建议方案

在 #017 架构的 `server/utils/logger.py` 中实现：
- 每次实验运行生成一个时间戳目录
- 记录配方参数、动作序列、速度曲线 CSV、报警和异常
- 师兄代码的 `utils/logger.py` 已有 CSV + JSON 报告功能，直接复用

## 验收标准
