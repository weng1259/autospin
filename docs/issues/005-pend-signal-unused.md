# Issue #005 — 驱动器到位信号（PEND）未利用

**日期**：2026-03-24
**提出人**：Claude（代码审查）
**状态**：open
**优先级**：低
**类型**：优化
**涉及文件**：`firmware/motor_control/motor_control.ino`

## 问题描述

2HSS57-C 驱动器提供 PEND+/PEND- 到位信号输出（手册第 5 页 §3.2）：当位置偏差小于参数 P26（默认阈值 10）时，集电极开路输出导通。

当前系统判断"电机是否到位"完全依靠 Arduino 的软件步数计数（`ax.position`）。但在闭环模式下，实际转子位置和脉冲命令之间可能存在偏差（加减速过渡、负载变化等），纯步数计数不能反映真实位置。

## 影响

- 当前影响不大：手动控制模式下人眼可以判断
- 未来做自动化流程时，需要精确知道"电机是否真的到达目标位置"再进行下一步操作（如放液、旋涂），纯步数计数不够可靠

## 建议方案

### 接线

每个驱动器的 PEND 输出接到 Arduino 空闲引脚（类似现在的 ALM 接法）：

```
驱动器 PEND+  →  Arduino D34/D35/D36（通过上拉电阻）
驱动器 PEND-  →  Arduino GND
```

PEND 是集电极开路输出（和 ALM 一样），需要上拉。Arduino 的 INPUT_PULLUP 即可。

### 固件

新增上报：`PEND:xyz`（类似 `ALM:xyz`），1 = 到位，0 = 未到位。

### 上位机

在运动完成后等待 PEND 信号确认，超时则提示可能丢步。

## 讨论记录

- 2026-03-24: 代码审查中发现。当前阶段优先级低，建议在自动化流程开发时再实施。需要额外 3 根信号线 + 3 个 Arduino 引脚。

## 验收标准

- [ ] 三轴 PEND 信号接入 Arduino 并上报
- [ ] 上位机能显示各轴到位状态
- [ ] 自动化流程中可等待 PEND 确认后再执行下一步
