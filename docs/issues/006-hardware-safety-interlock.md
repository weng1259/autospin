## 问题描述

### 问题 A：ALM 报警只显示不停机（原 #006）

系统上报 `ALM:xyz` 但不会停止运动或拒绝新命令。设备故障时仍可继续执行移动指令。

### 问题 B：ENA 使能输入未利用（原 #015）

2HSS57-C 驱动器有 ENA 使能输入（低电平有效，断开 = 电机失力矩），但当前未接线、未利用。系统只靠串口软件发 `S` 停止。如果浏览器崩溃、USB 断连或固件死机，没有独立的硬件去力矩通道。

## 影响

- ALM 不联动：过流/过压/缺相故障时电机继续转 → 烧驱动器或电机
- 无硬件急停：软件层全部失效时（USB 掉线、固件挂起），无法从外部切断电机力矩

## 建议方案

### ALM 联锁（固件层）

```
loop() 中每次循环检查 ALM 引脚（D31/D32/D33）：
  if (任何轴 ALM 触发):
    1. 立即停止所有轴运动
    2. 设置 fault 标志
    3. 上报 "ALM_FAULT:X1,Y0,Z0"
    4. 拒绝所有运动指令，直到收到 CLEAR_FAULT 命令
```

### ENA 硬件急停（接线 + 固件）

1. 三个驱动器的 ENA+ 串联 → 接到一个常闭急停按钮 + Arduino D34 输出
2. 正常运行：D34=HIGH → ENA 有效 → 电机有力矩
3. 急停触发：D34=LOW 或按钮断开 → ENA 失效 → 电机立即失力矩
4. 固件层：全局急停时 `digitalWrite(ENA_PIN, LOW)`，比串口发 `S` 更快更可靠

### 接线方案

```
Arduino D34 ──→ 急停按钮(常闭) ──→ 三台驱动器 ENA+ 串联
                                     ↓
                              各驱动器 ENA- ← 5V (共阳)
```
