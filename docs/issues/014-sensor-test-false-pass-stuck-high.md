# Issue #014 — 传感器测试可被“常高”故障误判通过

**日期**：2026-03-24
**提出人**：Codex（代码审查）
**状态**：open
**优先级**：中
**类型**：bug
**涉及文件**：`web_control/sensor_test.html`

## 问题描述

测试逻辑只要检测到某路为 `1` 就标记 `verified`。若线路短接高电平或传感器卡死常高，首次上报即可通过，无需实际触发动作。

这与“逐个验证传感器动态行为”的测试目标不一致。

## 影响

- 可能出现 9/9 通过但实际传感器故障
- 带故障进入正式运动，降低安全性

## 建议方案

- 按每路传感器记录状态序列，至少要求 `0 -> 1 -> 0`
- 启动时先采集基线，判定“常高/常低”并直接告警
- 在 UI 中展示每路通过条件和当前阶段

## 讨论记录

- 2026-03-24：静态审查发现 `verified` 的更新条件过于宽松。

## 验收标准

- [ ] 常高或常低输入不会被标记为通过
- [ ] 每路需完成完整触发-释放流程才计入进度
- [ ] 测试通过结果可准确反映传感器动态可用性
