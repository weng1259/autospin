# Issue #022 — 24V 配电使用杜邦线拧接，长期可靠性不足

**日期**：2026-03-24
**提出人**：Codex（审查 #027）
**状态**：open
**优先级**：中
**类型**：安全
**涉及文件**：`hardware/tutorials/02-电控接线教程.md`

## 问题描述

教程推荐杜邦线剪头拧线塞端子给三台驱动器配电。临时调试可行，但振动平台上接触电阻和松脱风险高，表现为间歇掉电、驱动器莫名报警。

## 建议方案

1. 改用合适线径软线 + 冷压端头（Y 型或 U 型）
2. 用端子排或分配块做 24V 星形配电
3. 各支路加保险丝
4. 文档区分"临时调试接法"和"长期使用接法"

## 验收标准

- [ ] 24V 配电改为端子排 + 冷压端头
- [ ] 教程更新接线方案
