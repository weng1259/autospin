# Issue #019 — 教程把"拔 USB 线"当急停方式

**日期**：2026-03-24
**提出人**：Codex（审查 #021）
**状态**：open
**优先级**：高
**类型**：安全
**涉及文件**：`hardware/tutorials/02-电控接线教程.md`

## 问题描述

教程建议 Z 轴测试时如果快撞到顶或底，"立刻拔掉 Arduino 的 USB 线"紧急停止。这不会形成规范的去力矩链路，且切断通信后 Z 轴无刹车会下滑。错误的急停动作会直接塑造组员操作习惯。

## 建议方案

1. 把拔 USB 的建议改为"立刻按空格键急停"（已实现）或"断 24V 电源总开关"
2. 明确标注"系统暂无合格硬件急停链路，仅允许低速、有人值守调试"
3. 待 #006 ENA 急停按钮接好后更新为正式急停操作指南

## 验收标准

- [ ] 教程中不再有"拔 USB 线"作为急停的表述
- [ ] 明确标注当前临时急停方式和正式急停方式
