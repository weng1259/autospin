# Issue #009 — Z 轴键盘方向在不同页面定义冲突

**日期**：2026-03-24
**提出人**：Codex（代码审查）
**状态**：open
**优先级**：高
**类型**：安全
**涉及文件**：`web_control/index.html`, `web_control/homing_test.html`, `web_control/sensor_test.html`

## 问题描述

主控面板中 `W/S` 与 Z 轴方向映射为 `W->B, S->F`，但回零页和传感器页映射为 `W->F, S->B`。同一个键在不同页面会产生反向运动。

跨页面调试时，操作者容易按惯性触发错误方向。

## 影响

- 可能出现“预期上升，实际下降”的危险动作
- 尤其 Z 轴靠近样品/工装时，误操作风险高

## 建议方案

- 定义统一方向规范（建议 `W=上, S=下`）并三页共用
- 抽取公共 `keyMap` 常量，避免页面各自维护
- 在 UI 明确显示键位与物理方向映射

## 讨论记录

- 2026-03-24：比对三个页面键盘映射时发现冲突。

## 验收标准

- [ ] 三个页面 `W/S` 对应同一物理方向
- [ ] 页面提示文本与实际按键行为一致
- [ ] 切换页面后方向操作无认知反转
