# Issue #006 — 驱动器报警（ALM）只显示不联动停机

**日期**：2026-03-24
**提出人**：Codex（代码审查）
**状态**：open
**优先级**：高
**类型**：安全
**涉及文件**：`firmware/motor_control/motor_control.ino`, `web_control/index.html`

## 问题描述

当前固件仅周期上报 `ALM:xyz`，但任意轴报警后不会自动停止连续运动。主控面板也只是把报警点亮红色，不会锁定移动按钮或阻止继续发命令。

这意味着系统处于驱动器故障态时，仍可能持续接收并执行运动指令。

## 影响

- 过流、超差、缺相等故障出现后仍被继续驱动，可能造成二次损坏
- 操作者误判为“可继续运行”，扩大故障范围
- 闭环报警下重复冲击，增加机械和电机热风险

## 建议方案

- 在固件主循环加入 ALM 联锁：任一轴 ALM 触发即 `running=false` 并上报 `FAULT:ALMxyz`
- 固件在故障未清除前拒绝 `XF/XR/...` 运动类命令，仅允许查询与复位命令
- 前端收到 `FAULT:` 后锁定运动按钮并提示“清故障后复位”

## 讨论记录

- 2026-03-24：审查发现 ALM 目前仅作为显示信号，未形成控制闭环。

## 验收标准

- [ ] 任一轴 ALM 触发后，三轴立即停止
- [ ] 报警状态下发送运动命令被拒绝并返回错误消息
- [ ] 前端报警后自动禁用运动控件，复位后恢复
