# Issue #008 — 全部回零完成后未执行 HR 坐标复位

**日期**：2026-03-24
**提出人**：Codex（代码审查）
**状态**：open
**优先级**：高
**类型**：bug
**涉及文件**：`web_control/homing_test.html`, `firmware/motor_control/motor_control.ino`

## 问题描述

回零页面在三轴都找到原点后，仅更新前端状态为“已回零”，没有发送固件支持的 `HR` 命令清零 `position` 计数。逻辑零点和固件坐标零点可能长期不一致。

这会导致“回零成功”与后续坐标显示不一致。

## 影响

- 主控面板显示坐标偏移，误导后续定位
- 自动流程若依赖位置值，可能在错误坐标系下执行

## 建议方案

- `homeNextAxis()` 判定 3/3 完成时自动发送 `HR`
- 等待 `HOME_RESET` 应答，超时则标记回零失败
- 在 UI 上区分“传感器回零完成”和“坐标复位完成”

## 讨论记录

- 2026-03-24：审查发现固件已实现 `HR`，但回零前端未调用。

## 验收标准

- [ ] 全部回零完成后自动发送 `HR`
- [ ] 固件返回 `HOME_RESET` 后才显示最终成功
- [ ] 回零后进入主控面板，位置显示为 (0,0,0)
