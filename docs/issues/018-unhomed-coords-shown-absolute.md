# Issue #018 — 未回零坐标被当成绝对毫米坐标展示

**日期**：2026-03-24
**提出人**：Codex（审查 #019）
**状态**：resolved（Phase 3.1 Slice 1-5 + grbl-Mega-5X：`MachineStatus.is_homed` 明确字段，UI/agent 都明示未归零；2026-04-22）
**优先级**：高
**类型**：安全
**涉及文件**：`firmware/motor_control/motor_control.ino`、`web_control/index.html`

## 问题描述

固件上电后 `position` 初始化为 0，主控页无条件把它换算成毫米画在带 HOME 标记的坐标系里。板子重启、重新烧录或换电后，页面把"未知真实位置"显示成"可信的 0 点附近坐标"。系统没有 `homed/unhomed` 状态区分。

## 影响

- 人工调试时误导操作者以为在零点附近
- 自动流程时直接导致撞机和取放位置错误

## 建议方案

1. 固件增加 `homed` 标志，上电默认 `unhomed`，回零成功后设为 `homed`
2. 状态上报增加 `HOMED:0/1` 字段
3. 前端未回零时：坐标显示"未校准"或只显示相对步数，不显示 mm；禁用绝对定位功能
4. 回零后才切换为毫米坐标系并启用 HOME 网格

## 验收标准

- [ ] 上电后坐标显示"未校准"
- [ ] 回零前禁用绝对定位相关功能
- [ ] 回零后坐标切换为毫米显示
