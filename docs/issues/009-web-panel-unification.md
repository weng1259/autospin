# Issue #009 — 网页面板公共模块抽取与行为统一

**日期**：2026-03-24（合并更新）
**提出人**：Claude + Codex
**状态**：obsolete（2026-04-23 —— `web_control/` 系列网页面板已废弃，L5 改 Streamlit；见 ADR-002/ADR-003）
**优先级**：高
**类型**：架构 + 安全
**涉及文件**：`web_control/index.html`、`web_control/homing_test.html`、`web_control/sensor_test.html`、`web_control/gripper.html`
**合并自**：原 #009（Z 轴方向冲突）+ Codex 审查 #025（前端代码三份复制漂移）

## 问题描述

### 问题 A：Z 轴方向定义冲突（原 #009）

- 主面板：`W→B（后退）, S→F（前进）`
- 回零/传感器页：`W→F（前进）, S→B（后退）`

同一按键在不同页面让 Z 轴反方向移动，危险。

### 问题 B：四个页面各自维护一套控制逻辑（Codex #025）

串口连接、速度初始化、长按→连续、停止、键盘映射、日志，全部复制粘贴。#009 的方向冲突只是第一个被发现的漂移，后续改限位提示、串口释放等都要改四处。

## 影响

- 方向冲突：操作者在旋涂台附近按 W，不同页面 Z 轴移动方向相反 → 撞坏样品
- 代码漂移：每次修 bug 要改四个文件，极易遗漏

## 建议方案

### 短期（修方向冲突）

统一所有页面 Z 轴键盘映射：`W = Z 轴正方向（向上远离工件）`，`S = Z 轴负方向（向下靠近工件）`。

### 长期（抽取公共模块）

```
web_control/
├── js/
│   ├── serial.js       # 串口连接/断开/生命周期（含 beforeunload 清理）
│   ├── motion.js       # 方向映射、速度命令、长按→连续、停止
│   └── ui-state.js     # 日志面板、状态指示、传感器/报警显示
├── index.html          # 只保留布局和特有逻辑
├── homing_test.html
├── sensor_test.html
└── gripper.html
```

页面只负责自己的视图和流程，共享行为（方向、连接、停止）统一来自公共模块。

## 验收标准

- [ ] 所有页面 Z 轴方向定义一致
- [ ] 公共串口模块抽取，页面不再各自实现连接逻辑
- [ ] 键盘映射从公共常量读取，改一处全生效
- [ ] 所有页面有"断开"按钮和 beforeunload 清理（同时解决 Codex #023）
