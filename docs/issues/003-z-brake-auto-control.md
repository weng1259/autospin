# Issue #003 — Z 轴刹车自动联动与状态确认

**日期**：2026-03-24（合并更新）
**提出人**：Claude + Codex
**状态**：open
**优先级**：中
**类型**：优化 + 安全
**涉及文件**：`web_control/index.html`、`server/drivers/relay.py`（未来）
**合并自**：原 #003 + Codex 审查 #024

## 问题描述

Z 轴电机带刹车（57J1880EC-1000-LS-SCG），通过 DSTUR-T80 USB 继电器 CH2 控制（通电 = 释放刹车）。存在两个问题：

### 问题 A：无自动联动（原 #003）

刹车释放/锁定完全手动。用户必须：先点"释放刹车" → 移 Z 轴 → 记得点"锁定刹车"。忘释放则堵转过流，忘锁定则失电下滑。

### 问题 B：状态无真实确认（Codex #024）

发送 CH2 开关命令后，前端只要写串口成功就显示"已释放/已锁定"。实际上这只表示"命令已发出"，不是"状态已确认"。DSTUR-T80 发 `0xFF` 可查询各路状态（返回 8 字节），但当前未利用。

## 影响

- 忘记释放：电机堵转 → 驱动器过流报警 → 长期损坏绕组
- 忘记锁定：Z 轴滑落 → 砸坏工件或旋涂台
- 状态误判：操作者在"以为已释放但实际没释放"的前提下移动 Z 轴

## 建议方案

**短期（网页面板）**：
1. Z 轴移动前自动发送释放刹车 → 等 0.3s → 再发脉冲
2. Z 轴停止后 → 等 0.2s → 自动锁刹车
3. 急停时 → 先停脉冲 → 锁刹车
4. 发送命令后查询 `0xFF` 确认状态，状态不一致则告警
5. 保留手动按钮作为维护 override

**长期（Python 后端，#017 架构）**：
SafetyManager 的 pre_check/post_check 统一处理刹车联动。

## 验收标准

- [ ] Z 轴方向按钮自动联动刹车释放/锁定
- [ ] 急停时先停电机再锁刹车
- [ ] 刹车状态通过 `0xFF` 查询确认，非仅靠写入推断
- [ ] 状态不一致时 UI 显示警告，禁用 Z 轴操作
- [ ] 手动释放/锁定按钮仍可用
