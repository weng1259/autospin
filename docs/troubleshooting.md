# 智能旋涂仪 — 踩坑汇总

> 记录开发过程中遇到的问题和解决方案，未来可直接转化为产品FAQ。

---

## 硬件相关

### 1. Z轴运动卡顿，发出"咚咚"声

- **现象**：Z轴移动时有明显卡顿和节律性异响，X/Y轴正常
- **原因**：Z轴电机 `57J1880EC-1000-LS-SCG` 带断电抱死型刹车（LS=刹车），不通24V时刹车锁死，电机在跟刹车硬拧
- **临时方案**：将Z轴刹车线（红+黑细线）直接接24V电源 +V/-V，手动释放刹车（接通后应听到"咔"声）
- **正式方案**：通过 DSTUR-T80 USB继电器 CH2 控制刹车24V通断（24V+V → CH2 COM，CH2 NO → 刹车红线，刹车黑线 → 24V -V）
- **注意**：临时方案下断电后Z轴会因重力下滑；正式方案中 CH2 OFF 时刹车锁死（断电抱死，安全）

### 2. Y轴电机线太短，X轴运动时扯到驱动器

- **现象**：Y轴电机装在X轴滑块上，X轴左右运动（300mm行程）时电线被扯到驱动器
- **原因**：电机线余量不足，没有走线拖链
- **解决方案**：
  1. 购买拖链（"10×20 拖链 尼龙"，1米约8元）+ 拖链固定座
  2. 若线太短，加购步进电机延长线（4芯1米，约5元）
  3. 临时方案：用扎带将线扎成大弧形固定在框架上
- **注意**：电源线和信号线分开走，不要捆在一起

### 3. 电源端子接线顺序易混淆

- **现象**：MAVN S-360-24 电源端子排列不直观，容易接错
- **原因**：端子顺序为 `+V +V -V -V ⏚ N L`（24V输出在左，220V输入在右）
- **解决方案**：三芯电源线颜色对应：棕色→L、蓝色→N、黄绿双色→⏚
- **注意**：先断电再接线；`+V ADJ` 旋钮出厂已调好24V，不要旋动

### 4. Arduino 5V引脚不够用（需接6根5V线到3个驱动器）

- **现象**：Arduino Mega只有2个5V引脚，但共阳极接法需给3个驱动器共6个端子供5V
- **原因**：PLS+ 和 DIR+ 都需要接5V，3个驱动器共6个端子
- **解决方案**：采用驱动器之间串联跳接——从Arduino引出2根5V线到第一个驱动器，然后在驱动器端子间用短线跳接到第二、第三个驱动器
- **注意**：驱动器端子孔较大，同一端子塞2根线没问题

### 5. 夹爪上电后不动（正常现象）

- **现象**：给夹爪控制器接上24V电源（V+/V-绿色端子 + COM-）后，电机嗡嗡响但夹爪不动
- **原因**：夹爪的开合由独立的 `24V` 控制引脚控制，仅接电机电源不会触发动作
- **解决方案**：通过 DSTUR-T80 USB继电器的 CH1 给 `24V` 控制引脚通电/断电来控制夹合/松开
- **注意**：电机嗡嗡声是步进电机通电锁定的正常表现

### 6. 继电器咔声正常但夹爪不夹合

- **现象**：发送CH1 ON指令后听到继电器"咔"声，但夹爪没有动作
- **原因**：继电器端接线错误（通常是接了NC端而非NO端，或24V回路没闭合）
- **排查步骤**：
  1. 确认接的是 NO 端（常开），不是 NC 端（常闭）
  2. 万用表量 CH1 ON 时 COM 和 NO 之间是否导通
  3. 确认夹爪 COM- 已接到 24V电源 -V（必须形成完整回路）
  4. 确认 24V电源 +V 接到继电器 COM 端
- **注意**：继电器触点额定 10A/30VDC，驱动夹爪绰绰有余

### 7. USB继电器端口找不到或发送指令无响应

- **现象**：`ls /dev/cu.usb*` 看不到继电器端口，或发送指令后无响应
- **原因**：USB线接触不良、端口被其他程序占用、或指令格式错误
- **解决方案**：
  1. 重新拔插USB线，换个USB口试试
  2. `lsof /dev/cu.usb*` 检查端口是否被其他程序占用
  3. 确认波特率为 9600
  4. 确认指令校验和正确：校验和 = 0xA0 + 通道 + 开关状态（取低8位）
- **注意**：DSTUR-T80 的端口名通常含 `usbmodem`（如 `/dev/cu.usbmodem6670E00119391`），和 Arduino 的 `usbserial` 不同

## 软件相关

### 8. X轴和Z轴方向在控制面板中是反的

- **现象**：网页控制面板中X轴和Z轴实际运动方向与预期相反，Y轴正常
- **原因**：X轴和Z轴的电机安装方向与软件逻辑方向相反
- **解决方案**：在固件 `firmware/motor_control/motor_control.ino` 中对调X/Z轴的 HIGH/LOW 方向逻辑
- **注意**：上传固件前必须先关闭网页控制面板

### 9. 信号线误接模拟引脚

- **现象**：按教程接线后电机无响应
- **原因**：将信号线接到了 A2/A3（模拟引脚），而非 D2/D3（数字引脚）
- **解决方案**：D2-D7 位于 Arduino Mega USB口旁的小排针（标注 DIGITAL），不是板中部的大排针区域
- **注意**：Arduino Mega 的引脚排布——D0-D13在USB口一侧的小排针，D22-D53在板中部的双排大引脚

## 工具/环境相关

### 10. Web Serial API占用串口，固件无法上传（需重启电脑）

- **现象**：网页控制面板连接Arduino后，关掉网页再上传固件报串口错误，拔插USB无效
- **原因**：浏览器Web Serial API连接过串口后，CH340驱动状态未完全释放
- **排查过程**：检查进程占用（无）→ 拔插USB（无效）→ 尝试旧版avrdude（无效）→ 重启电脑恢复
- **解决方案**：重启电脑后CH340驱动完全复位
- **预防措施**：操作顺序为：关网页 → 拔USB → 插USB → 上传固件。**每次上传固件前必须先关闭网页控制面板**

### 11. Arduino CH340国产版在Mac上无法识别

- **现象**：Arduino Mega（CH340芯片国产版）插入Mac后端口列表为空
- **原因**：macOS不自带CH340驱动，国产版使用CH340 USB转串口芯片（正版用ATmega16U2免驱）
- **解决方案**：安装CH340驱动后，端口显示为 `/dev/cu.usbserial-110`
- **注意**：正版Arduino用ATmega16U2（Mac免驱），国产版用CH340（必须装驱动）
