# Phase 2: Hardware Acceptance & Experimental Validation Plan

版本：1.0  
日期：2026-08-05  
适用项目：`autospin`

## 1. 目的与放行原则

本计划验证迁移后的软件动作是否与真实机械、电气和工艺行为一致。测试不以
“API 返回成功”为唯一依据，必须同时确认：

1. 软件记录的命令、时间和状态正确；
2. 设备反馈与软件状态一致；
3. 现场观察或独立测量证明机械动作确实正确；
4. 异常时设备进入已定义的安全状态。

验收按以下顺序进行，前一阶段未通过不得进入后一阶段：

```text
只读检查 → 单设备空载 → 工装/耗材 → 单片闭环
         → 多槽热台 → 三片交错 → 完整旋涂工艺 → 故障与恢复
```

本计划是人工监督的硬件验收文件，不授权无人值守运行。首次真实执行必须有
设备负责人、软件操作员和安全观察员在场。

## 2. 角色、环境和通用前置条件

### 2.1 角色

| 角色 | 职责 |
|---|---|
| 设备负责人 | 确认机械限位、夹具、热台、旋涂腔和电气状态 |
| 软件操作员 | 执行指定版本、保存日志和记录操作 ID |
| 安全观察员 | 手持或站在实体急停可达位置，独立判断是否中止 |
| 实验负责人 | 批准样品、溶剂、温度、速度和时间容差 |

同一人可以兼任软件操作员和记录员；运动测试期间不得取消安全观察员。

### 2.2 测试前冻结信息

每次验收先记录：

- Git commit 或完整源码归档校验值；
- `config/devices.yaml`、`config/hardware.yaml`、
  `config/coordinates.yaml` 的归档副本和校验值；
- Raspberry Pi、Python、固件、GRBL 和设备驱动版本；
- XYZ、移液滑台、夹爪、热台、旋涂电机及继电器的设备编号；
- 当天环境温度、湿度和测试人员；
- 当前安装的夹具、移液头、玻璃片规格和热台表面状态。

### 2.3 通用安全检查

- 清空运动包络内的工具、线缆、样品盒和松散物体。
- 确认 XYZ 限位、软限位、Z 轴制动、保护罩和旋涂盖状态。
- 确认夹爪、吸头和玻璃片不会在掉落后进入旋转部件或电气区域。
- 热台测试准备隔热手套、镊子、耐热托盘和独立温度计/热电偶。
- 溶剂测试在适用的通风、防火和废液条件下进行。
- 实体急停和 Web 急停均可触达；安全观察员知道总电源断开位置。
- 首轮测试使用空载、低速、低温和替代液，逐级放大，不直接使用正式工艺。

### 2.4 通用停止条件

出现以下任一情况立即急停并停止该测试阶段：

- 位置或运动方向与预期不符；
- 未归零却发生真实移动；
- 任何软限位、硬限位、GRBL `ALARM` 或异常碰撞；
- 线缆拉扯、玻璃片滑移、夹爪失持、吸头脱落；
- 热台温度失控、旋涂异常振动、异味或不正常噪声；
- 软件显示成功但设备未动作，或软件状态与实物不一致；
- 急停后仍继续启动新动作。

停止后不得直接重试。应保存日志和现场状态，断开危险能源，记录偏差，再由
设备负责人批准恢复步骤。

## 3. 测量设备与记录要求

建议准备：

- 钢尺、塞尺或量块；需要定量重复性时使用百分表/激光位移计；
- 独立热电偶或校准温度计；
- 60 fps 以上视频；自旋滴液校准建议 240 fps 或光电触发记录；
- 秒表仅用于粗测，关键反溶剂时序使用视频帧或独立采集器；
- 三片有永久编号的空白玻璃片和至少九个槽位标识；
- 水或经实验负责人批准的替代液，以及称量纸/天平（如需验证体积）。

每个动作至少保存以下证据：

- 操作 ID、开始/结束时间和 ActionRecord；
- 命令坐标、设备反馈坐标、现场测量值；
- 视频文件名及关键帧时间；
- 通过/失败、偏差描述、处置和复测编号。

建议在执行前由实验负责人填写本计划所有标为“批准值”的容差。未填写容差
不能判定通过。

## 4. Gate A：只读连接与配置检查

### 目标

证明新系统连接的是预期设备，并且未混用旧 `autospin_system` 入口。

### 步骤

1. 保持执行机构处于安全断能状态，启动新 Web 服务。
2. 检查 `DeviceRegistry.from_config()` 注册的七类设备：gantry、relay、
   gripper、spincoater、heater、pipette、linear_stage。
3. 读取串口映射、设备状态和 GRBL 设置，不发出运动或温度设定命令。
4. 确认当前进程命令行和导入路径使用 `src.*`，而不是
   `autospin_system.*`。
5. 执行软件测试：`python -m pytest -q`。

### 通过标准

- 所有设备身份和端口与接线表一致；共享 RS485 设备没有重复占用串口。
- 未连接、故障和未归零状态不会显示为可执行状态。
- 软件测试通过；任何跳过项和警告均有记录。

## 5. Gate B：XYZ 空载测试

### 目标

验证归零方向、坐标系、软限位、安全高度运动、位置反馈和重复性。

### 前置条件

- 移除玻璃片、吸头和液体，夹爪保持打开。
- 将 Z 轴置于人工确认的安全区域。
- 首次真实测试优先使用 `tools/gantry_runtime_smoke.py` 的显式执行保护，
  不直接运行完整实验。

### 步骤

1. 读取状态，记录 `is_homed`、机器坐标、报警和限位输入。
2. 执行一次归零，观察 X/Y/Z 方向和 Z 制动释放/锁定。
3. 移动到中央安全点，再分别进行小距离 X、Y、Z 单轴运动。
4. 以低速访问已批准的工作包络代表点；每次都先升至
   `safe_travel`，再移动 XY，最后下降 Z。
5. 在不发送真实移动的条件下请求一个超软限位坐标，确认软件拒绝。
6. 对一个中央点和一个边界附近点各往返 10 次，记录命令值、反馈值和外部测量。
7. 结束时返回批准的安全停放点，而不是假定坐标零点适合停放。

### 通过标准

- 归零方向、限位触发和坐标符号全部正确。
- 任意 XY 改变前均先达到安全 Z；没有斜穿夹具的路径。
- 超软限位请求在下发运动前被拒绝。
- 10 次往返无丢步、报警或位置漂移；最大误差和重复性均不超过设备负责人批准值。
- 软件反馈位置与现场测量方向一致。

## 6. Gate C：Tip pickup 与移液高度测试

### 目标

验证旧吸头弹出、新吸头安装、`tip_present` 反馈、滑台安全位置和保存的
dispense clearance。

### 步骤

1. 使用空吸头架和废吸头容器检查 XYZ/滑台路径，不安装吸头。
2. 装入一个测试吸头，在低速下执行 ChangeTip：已有吸头时先到废料位弹出，
   再到指定槽位取新吸头，最后退回安全高度。
3. 连续在三个不相邻槽位重复，确认生成槽位坐标方向和 8×12 排列一致。
4. 每次记录取头前后的实时 `tip_present`；遮挡或故意缺失吸头执行一次负向测试。
5. 使用替代液执行低体积吸取/排液，确认前驱液与反溶剂的保存高度分别作用于
   线性滑台，而不是只显示在 UI。
6. 进行 10 次取头/弹出循环，检查吸头同心度、脱落、弯曲和槽位损伤。

### 通过标准

- 旧吸头进入废料位，新吸头垂直装入且不会碰撞相邻吸头。
- 新吸头安装后 `tip_present=true`；缺头或未知反馈使动作失败且不继续吸液。
- 滑台顺序为安全位→工艺位→安全位，实际间隙在批准范围内。
- 10 次循环无漏取、双取、吸头脱落或错误继续运行。

## 7. Gate D：Gripper 循环与单片闭环测试

### 目标

验证夹爪开合、玻璃片持力、取放高度、旋涂位和原槽返回。

### 步骤

1. 空载开合 20 次，观察继电器状态、机械行程和发热。
2. 使用一片编号空白玻璃，低速执行：原槽安全上方→下降→夹紧→抬升。
3. 保持 30 秒并以安全速度水平移动，确认无滑移。
4. 放到旋涂位并释放，再重新夹取。
5. 放到热台冷态槽位并释放，再重新夹取。
6. 返回该玻璃片原始 substrate slot，确认编号和槽位一致。
7. 完成 10 个“原槽→旋涂位→冷态热台→原槽”循环。

### 通过标准

- 空载 20 次和带片 10 次均无卡滞、误动作、明显温升或状态不一致。
- 玻璃片全程不滑移、不旋转、不崩边。
- 放片后完全脱离夹爪；取片时夹持位置可重复。
- 样品最终返回原槽，而不是默认槽或下一轮槽。

## 8. Gate E：Hotplate 多槽与温度稳定测试

### 目标

验证九槽坐标、safe-above 点、槽位占用/释放、温度稳定闭环和热态取放。

### 步骤

1. 热台断热，在九个槽位依次执行 safe-above、放片、取片；使用编号玻璃记录槽位。
2. 检查 3×3 生成方向、间距和每槽边缘余量。
3. 选择中心、角部和另一个代表槽，以低温设定值运行。
4. 用独立热电偶记录 PV、独立温度和稳定时间。软件必须等待连续三个样本进入
   默认 ±1 °C 稳定窗后才允许进入下一阶段。
5. 在批准工艺温度下重复代表槽热态取放，确认夹爪、玻璃和线缆热安全。
6. 占用一个槽位时尝试规划第二片进入同一槽，确认被资源管理器拒绝；取回后再
   分配，确认可以复用。

### 通过标准

- 九槽均无碰撞且实际玻璃中心/边缘余量满足批准值。
- 软件 PV 与独立温度差不超过实验负责人批准值；超时或温度不稳定时实验失败。
- 已占用槽不能被重复分配；只有完成取回后才能复用。
- 热态取放无粘连、翘曲、掉片或夹爪热损伤。

## 9. Gate F：三片交错退火测试

### 目标

验证共享 gantry 在多片退火重叠时按实际放片时间计时，并在到期前移动到对应
玻璃片上方等待。

### 测试方案

使用三片编号玻璃 A、B、C 和三个不同热台槽。先以冷态/短时替代方案执行，
通过后再使用批准温度。为制造重叠，三片采用相同或相近退火时间，并使后续片
的前处理发生在前一片退火期间。

### 步骤

1. 保存编译后的完整 action plan，记录每片 hotplate slot 和计划截止时间。
2. 用视频或独立时间记录每片“夹爪打开、样品完成放置”的时刻
   `T_place(A/B/C)`。
3. 记录每片开始移动到 safe-above、到达 safe-above、开始夹取和离开热台的时刻。
4. 确认等待发生在对应槽的 safe-above，且等待期间没有下降接触玻璃。
5. 确认 A 退火时 B/C 的非冲突动作能够运行。
6. 确认到期取片没有插入到前驱液吸取/排液或反溶剂/旋涂关键块内部。
7. 确认 A、B、C 分别返回原始槽，并核对结果中的 sample state 为 `returned`。

### 计算与通过标准

对每片计算：

```text
实际退火时间 = T_pick_start - T_place
退火时间误差 = 实际退火时间 - 配方退火时间
预定位裕量 = T_due - T_safe_above_arrival
```

- 每片计时起点必须是实际放片完成时刻，而不是批次开始或计划估算时刻。
- 实际退火时间误差在实验负责人批准范围内，且不得提前取片。
- 机械臂在到期前已到达正确 safe-above；若未赶到，应判失败而不是掩盖迟到。
- 三片槽位、编号和返回位置完全正确，没有重复占用。

## 10. Gate G：Spin + antisolvent 时间校准

### 目标

验证电机确认启动后的绝对自旋时间、分段转速、反溶剂预定位和真实滴液时刻。

### 步骤

1. 空载且盖好防护罩，以低速执行启动、保持、停止，检查真空继电器和停止路径。
2. 使用平衡良好的替代基片逐级测试工艺转速，记录命令转速和实际反馈转速。
3. 执行两段或多段 spin profile，记录每段命令切换和实际达到目标范围的时刻。
4. 使用水或批准替代液，确保移液器在电机启动前到达旋涂滴液位置。
5. 同步记录：电机启动确认帧/ActionRecord、视觉上开始旋转、滴液器开始动作、液滴
   接触基片、各段结束及停止。
6. 每个反溶剂时点至少重复 10 次；建议使用 240 fps 视频按帧计算，而不是人工秒表。
7. 在滴液窗口前触发一次普通非急停操作，确认不会插入 gantry/退火取片动作。

### 计算与通过标准

```text
控制时序误差 = T_dispense_command - T_motor_confirmed_start - 配方 at_s
实际落液误差 = T_liquid_contact - T_motor_confirmed_start - 配方 at_s
```

- `WaitUntilSpinElapsed` 的零点是确认的 motor-start epoch。
- 不允许因前一段 sleep 或通信耗时产生逐段累计漂移。
- 10 次控制时序和实际落液的最大误差、平均值和标准差均应记录；放行界限由
  实验负责人按工艺窗口批准。若尚无工艺界限，可将 ±0.2 s 作为待批准的初始
  工程目标，而不是自动视为合格标准。
- 任何关键窗口内不得发生样品搬运或其他共享 gantry 动作。

## 11. Gate H：急停测试

### 目标

验证急停同时阻止新动作、停止危险硬件，并且不会把未知状态误报为可恢复状态。

### 测试矩阵

依次在以下状态触发 Web 急停；实体急停另按设备电气安全程序验证：

1. 空闲；
2. XYZ 安全区域低速移动；
3. 夹爪闭合持有替代片；
4. 移液器等待或低风险替代液动作边界；
5. 旋涂低速运行；
6. 热台升温/稳定等待；
7. `WaitUntilElapsed` 长等待；
8. 三片交错计划运行期间。

### 每项检查

- 记录急停请求时刻、API 响应、各设备停止/断能时刻和最终反馈。
- 确认活动实验取消事件先被设置，操作 gate 被终止，后续 action 不再启动。
- 确认 spin 停止、真空/危险继电器进入安全状态、XYZ 停止、移液动作停止。
- 检查夹爪断电策略是否会掉片；该策略必须由机械风险评估决定，不能仅以
  “全部继电器关闭”为默认正确答案。
- 急停后尝试直接继续实验，系统应拒绝或要求重新连接、状态确认和归零。

### 通过标准

- 每种状态均无急停后新动作启动。
- 物理停止时间不超过设备安全风险评估批准值；报告必须记录实测值，不能只记录
  HTTP 202/200 响应时间。
- 急停后的 homed、tip、sample、hotplate 和 heater 状态按未知/需确认处理。
- 恢复必须是新的受控流程，不允许从被打断 action 中间自动续跑。

## 12. Gate I：断电恢复检查

### 目标

证明意外断电和服务重启不会自动恢复危险动作，也不会信任断电前的软件状态。

### 测试场景

在设备负责人批准的低风险条件下分别测试：

- 空闲断电；
- XYZ 停在非原点安全位置；
- 夹爪持有替代片；
- 热台低温加热；
- 旋涂低速运行；
- 三片计划中有热台槽占用。

### 步骤

1. 记录断电前全部设备、样品和槽位状态。
2. 按批准方式切断控制电源；观察继电器、制动、夹爪、热台和旋涂的失电状态。
3. 恢复电源但暂不启动服务，确认设备不会自行旋转、加热或移动。
4. 启动服务，确认不会自动续跑未完成实验。
5. 检查状态是否正确标为未连接、未归零或需人工确认。
6. 人工清点样品和热台槽位，处理热片/掉片后，再重新连接和归零。
7. 通过只读状态和单设备 smoke test 后，才允许创建新实验。

### 通过标准

- 上电和服务启动均不产生自动运动、旋转、加热或排液。
- 断电前的 `is_homed`、活动 action 和内存 hotplate ownership 不被当作可信现状。
- 未完成实验被记录为失败/中断，不自动从中间恢复。
- 操作员完成样品/槽位人工对账、连接和重新归零后才能开始新批次。

## 13. 最终工艺放行

只有 Gate A-I 全部通过，才进入正式前驱液与反溶剂的小批量验证。建议顺序：

1. 单片、低价值基底、替代液；
2. 单片真实液体；
3. 三片真实液体但保守参数；
4. 重复三批，比较膜外观、滴液时序和退火时间；
5. 实验负责人签字后再开放常规多轮运行。

软件测试通过不能替代工艺放行，工艺结果良好也不能掩盖急停或状态反馈失败。

## 15. `autospin_system` 目录处置评估

### 当前结论

`autospin_system/` 是废弃的中间实现，不是行为参考。唯一权威旧行为来源是独立的
`AutoSpinmotorSystem` 项目。Phase 1 已解除 pytest、诊断工具和部署说明对该目录的
活动依赖；生产执行路径始终使用 `src` backend/adapter/driver。

该目录在完成静态搜索、无目录演练和部署验证前仍保持原样，但硬件验收不得运行或
引用其中的代码、测试、协议生成器或示例来判断行为正确性。

### 建议处置顺序

1. Phase 2 期间冻结该目录，禁止从旧入口启动任何实验或诊断。
2. 使用已经迁移到 `DeviceRegistry` 的新诊断入口完成硬件验收。
3. 仅从 `AutoSpinmotorSystem`、硬件手册和实测证据确认行为与寄存器依据。
4. 在临时分支或归档副本中移除旧目录，执行：完整 pytest、Web 启动、
   `DeviceRegistry.from_config()`、七设备只读连接和所有新 smoke tests。
5. 验证部署包、systemd/启动脚本和 Raspberry Pi 实际目录中都没有旧包引用。
6. 通过以上删除演练后再提交独立删除变更，并保留 Git tag/只读压缩归档以便追溯。

`autospin_system/` 仍是后续删除目标。删除应作为独立变更完成，不得混入硬件验收、
工艺参数调整或实验行为修改。
