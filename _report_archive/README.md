# Report Archive

This folder stores materials that are useful for traceability but do not need
to appear in the main project-directory screenshot for a presentation.

## Archived Content

- `Migration record/`: migration-stage records and implementation notes.
- `migration_snapshot/`: historical snapshot captured during migration.
- `HARDWARE_ACCEPTANCE_TEST_PLAN.md`: hardware acceptance test planning.
- `MIGRATION_IMPLEMENTATION_REPORT.md`: migration implementation summary.
- `LEGACY_*.md`: legacy-system retirement and cleanup records.
- `RASPBERRY_PI_LEGACY_DEPLOYMENT_AUDIT.md`: legacy Raspberry Pi deployment audit.

## Presentation Note

For a directory-structure slide, these files can be summarized as:

> Archived migration, legacy cleanup, and acceptance-test records. They are kept
> for traceability, but they are not part of the main runtime structure.
