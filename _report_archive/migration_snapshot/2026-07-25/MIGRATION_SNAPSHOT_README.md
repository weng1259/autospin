# Migration Snapshot

The preserved migration deliverable is stored under:

```text
migration_snapshot/2026-07-25/
```

It contains copies of migrated source, configuration, tests, tools, and
project reports at the time of snapshot creation. `MANIFEST.sha256` records
the SHA-256 hash of every copied file.

The snapshot is archival material, not an import path and not a second runtime
implementation. Development and deployment continue to use the repository
root files.
